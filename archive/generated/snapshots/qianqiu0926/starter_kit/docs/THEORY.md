# LoomQ 理论命题与原创贡献

## 声明边界

本文给出的是针对 LoomQ 已发布语言子集的工程命题、证明草图和可执行检查器，不声称是经过同行评审的形式化结果，也不声称其组合在全球范围首创。“原创贡献”特指本参赛实现中已落地、有对照测试和适用边界的工程组合。

## 1. 证明携带的目标 IR 执行

设源程序经严格解析得到电路 (C)，目标 emitter 为 (E_T)，与 emitter 代码路径分离的目标解析器为 (R_T)。实际执行对象定义为：

\[
C_T = R_T(E_T(C)).
\]

证书同时检查：

1. 扩展广播并扁平化寄存器后的操作轨迹逐项相等，包括门名、qubit 索引和 binary64 参数；
2. 测量的 `qubit → cbit` 映射及顺序相等；
3. 从规范初态出发的状态向量在全局相位意义下相等；
4. 计算基测量分布相等。

### 命题 A（直线 emitter 的语义保持）

在当前不做优化的 emitter 边界内，如果规范化操作轨迹与测量映射都相等，则对任意输入态，(C) 与 (C_T) 产生相同的量子演化和经典测量分布。

**证明草图。** 操作轨迹的每一项使用同一门矩阵、同一参数和同一组扁平 qubit。对前缀长度归纳，每个前缀的复合算子相等；再由相同的测量映射得到相同经典分布。状态向量和概率检查是对解析器/语义实现错误的第二道防线，不用来代替轨迹证明。

全局相位不变距离直接通过相位对齐计算：

\[
d(\psi,\phi)=\min_\alpha\lVert\psi-e^{i\alpha}\phi\rVert_2,
\]

避免了直接计算 `sqrt(2-2|overlap|)` 在近似相等时的消去误差。

### 执行精化

`run()` 只执行 (C_T)，不再执行内存中的源 (C)。返回结果包含源 IR、目标文本和证书的 SHA-256，使一个 job 可精确追溯到其实际执行的目标产物。这个设计同时受 translation validation 和 proof-carrying code “先检查证据、再接受代码”思想启发，但证书是 LoomQ 子集专用收据，不是通用 PCC 证明对象。

## 2. 确定性 counts 的误差界

设理论概率为 (p_i)，shots 为 (S)，配额 (q_i=Sp_i)。最大余数法先分配 (\lfloor q_i\rfloor)，再把剩余名额给小数余数最大的状态。

### 命题 B（份额和单态误差）

\[
\sum_i n_i=S,\qquad n_i\ge 0,\qquad |n_i/S-p_i|<1/S.
\]

**理由。** 每个 (n_i) 只能是配额的下取整或上取整，因而误差严格小于 1 shot；剩余名额数由 (S-\sum_i\lfloor q_i\rfloor) 定义，所以总和严格为 (S)。这是可复现的理论分布展示，不伪装成有独立随机噪声的真机采样。

## 3. L2 的受保护约束投影

设 (H(p)) 是从用户原文中以高精度规则抽取的硬约束，(M(p)) 是 LLM 计划。守卫函数 (G) 对 (H) 已检出的每个字段强制使用原文值，只对原文规则未覆盖的字段保留模型解释。

### 命题 C（已检出约束不可被 LLM 弱化）

若后端 (b) 被确定性 selector 接受，则 (b) 满足 (H(p)) 中每个已检出谓词，与 (M(p)) 是否遗漏、矛盾或提示注入无关。

**证明草图。** (G) 用 (H) 覆写已检出字段；selector 对能力表逐谓词过滤，不接受任意不满足项。因此结论由程序控制流直接得出。

命题只覆盖被确定性规则检出的明确数值、真机/模拟器、费用、排队、账号和平台约束；隐喻、反语和完全开放的任务意图仍是明确限制。

## 4. Hybrid 经典块的测量参数化等价

对给定测量位向量 (c\in\{0,1\}^m)，Hybrid AST 只包含整数、寄存器、加减、`==/!=` 和有界嵌套分支。

### 命题 D（对所有测量赋值的经典等价）

在不耗尽临时寄存器且算术不溢出目标实现的前提下，对每个 (c)，编译后 RISC-V 的 `r1..r9` 终值等于 AST 大步语义结果。

**证明草图。** 对表达式结构归纳：字面量、寄存器和测量位的编译直接保持值，加减和一元负号由归纳假设得证。对语句序列归纳：赋值复制已保持的表达式值，分支指令在条件为真/假时分别进入对应子序列。没有循环，所以必然终止。

## 5. 微弧度 Quantum RISC-V 的误差证书

参数门角度先按 (2\pi) 归一化，再编码为：

\[
\hat\theta=\operatorname{round}(10^6\theta)/10^6,
\qquad |\hat\theta-\theta|\le 5\times10^{-7}\ \text{rad}.
\]

`QRY/QRZ/QCU1` 使用 `funct7=1`，`rd` 指向存放有符号微弧度整数的经典寄存器。对 (\Delta=\hat\theta-\theta)：

\[
\lVert R_y(\hat\theta)-R_y(\theta)\rVert
\le |\Delta|/2,
\]

\[
\lVert R_z(\hat\theta)-R_z(\theta)\rVert
\le |\Delta|/2,
\]

\[
\lVert CU1(\hat\theta)-CU1(\theta)\rVert
\le |\Delta|.
\]

前两式由 (2|\sin(\Delta/4)|\le|\Delta|/2) 得到，后一式由 (2|\sin(\Delta/2)|\le|\Delta|) 得到。对 (n_r) 个 RY/RZ 和 (n_c) 个 CU1，乘积算子的 telescoping bound 为：

\[
\lVert\hat U-U\rVert
\le (n_r/2+n_c)\,5\times10^{-7}.
\]

实现同时使用更保守的“参数门数 × 0.5 μrad”作为测试上界。`RY/RZ` 的 (2\pi) 归一化最多引入不可观测的全局符号，`CU1` 则严格 (2\pi) 周期。

## 6. 本参赛实现的原创工程组合

1. **Target-IR Proof Receipt**：把独立回读、规范轨迹、全局相位距离、测量映射、产物哈希和“执行回读目标”组成一个 fail-closed 运行时边界。
2. **Protected Constraint Projection**：LLM 仅补充未被确定性规则覆盖的语义；用户原文中的硬约束有更高信任级别，并产生可读决策轨迹。
3. **Two-profile Quantum RISC-V**：在一个 `custom-0` R-type 编码中，用 `funct7` 区分离散门与参数门，避免把低精度角度硬塞进 5 位 qubit 字段，同时给出端到端数值上界。
4. **测量参数化的 Hybrid oracle**：将量子测量视为经典编译结果的自由布尔输入，对小电路穷举所有分支，不让单次随机量子测量遮蔽经典控制错误。

实现与反例测试分别位于 `loomq/pipeline.py`、`loomq/verification.py`、`loomq/agent.py`、`loomq/quantum_riscv.py`、`riscv_emulator.py` 和 `tests/`。
