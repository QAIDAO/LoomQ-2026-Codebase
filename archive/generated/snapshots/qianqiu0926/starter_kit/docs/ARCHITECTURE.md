# 架构与正确性论证

## 1. 单一语义核心

`ir.py` 把 QASM 转为 `Circuit(qregs, cregs, operations)`；`Gate` 和 `Measure` 的操作数是经过声明、范围和互异性检查的引用。三种目标代码生成器只能读取这个对象，无法各自重新解释源文本。

这对应成熟编译器的三段式结构：前端负责源语言语义，通用 IR 承载分析与变换，后端负责目标代码。对本题而言，保持 IR 小而强约束，比引入大而未使用的编译框架更容易审计。

## 2. 解析策略

- C/CPP 风格注释先剥离；源文件必须以 `OPENQASM 2.0;` 开始。
- 只允许题面 12 门；参数门恰好一个有限实数参数。
- 角度使用 Python AST 的白名单节点求值，仅开放常数、`pi`、基本算术；函数调用、属性和下标均拒绝。
- 整寄存器门/测量在 IR 中显式展开，消除 emitter 对广播语义的歧义。
- 多比特门要求操作数互异；声明、索引、参数和 arity 错误立即失败。

## 3. L1 语义

内部状态向量采用 basis index 的第 `k` 位对应扁平 qubit `k`。单比特门逐对更新幅度；受控门只交换或加相位，不构造指数大小的完整门矩阵。每次模拟结束检查范数近似 1。

测量映射先写入扁平经典位，再用 `reversed(cbits)` 生成 `c[n-1]...c[0]`，因此最右侧恒为 `c[0]`。精确概率通过最大余数法配额为整数 counts，保证：

1. 每项非负；
2. 总和严格等于 shots；
3. 确定性复现；
4. 与理论分布的舍入误差不超过一个 shot。

## 4. Translation validation

`verification.py` 不信任 emitter 内存对象，而是重新解析已生成的 SpinQ QASM 2、Braket QASM 3 和 OriginIR。证书同时比较规范操作轨迹、测量映射、全局相位不变的完整状态向量和测量分布。这个“翻译验证”边界能发现门名映射、相位、参数序列化、寄存器展平和测量位序错误。

测试再使用随机电路和逆门恒等式建立 metamorphic oracle，并专门注入“概率不变但相位错”和“额外门相互抵消”两类反例。`pipeline.py` 只在证书通过后执行独立回读的目标电路，并把证书收据写入 result meta。

## 5. L2 可信闭环

模型返回受约束 JSON 计划，而不是直接成为最终真相源：

- 已知目标族（Bell、GHZ、均匀叠加、基态）由确定性 builder 生成；
- 其他 QASM 必须通过同一个 L1 parser；
- 可计算目标分布会与状态向量结果比较；
- 后端建议由模型抽取语义，但用户原文中的明确硬约束会经本地规则受保护地投影回计划；
- 最终候选只由 `backend_capabilities.json` 逐项筛选，回复显示原文约束轨迹和被覆写的模型字段；
- JSON 或 QASM 失败最多反馈一次，避免无界重试和预算失控。

系统每个 case 至少调用一次 `llm_client.chat_completion`，满足官方 L2 有效调用要求；缺少环境变量时在网络前失败且不回显任何 key。

## 6. L3 编译

Hybrid-QASM classical block 使用独立 tokenizer 与递归下降 parser，AST 节点覆盖字面量、`r1..r9`、`c[k]`、一元负号、加减、条件和嵌套分支。

- `rN → xN`；`c[k] → x(10+k)`；
- 表达式临时值从不与用户/测量寄存器重叠的高寄存器分配；
- `==` 用反向 `bne` 跳到 else，`!=` 用反向 `beq`；
- 所有路径合流到唯一标签；末尾清零实际使用过的临时寄存器。

没有循环、动态内存或未定义控制流，因此官方 1000 步模拟器上可确定终止。

## 7. 威胁模型

| 威胁 | 控制 |
|---|---|
| QASM 参数代码注入 | AST 白名单，拒绝 Call/Attribute/Subscript |
| Prompt injection 改写系统契约 | system contract 把用户文本定义为数据；最终仍由本地工具判定 |
| LLM 遗漏/矛盾后端硬约束 | 受保护约束投影；已检出原文字段不可被模型覆盖 |
| emitter 生成与执行对象脱钩 | 证明携带 pipeline 只执行独立回读目标电路 |
| API key 泄露 | 只从环境读取；异常不包含请求头或 key |
| Web 路径穿越 | 静态资源 `resolve()` 后限制在 assets 根目录 |
| 超大 Web 请求 | 1 MiB 请求上限；shots 上限 |
| 本地服务外露 | 默认监听 `127.0.0.1` |
| 假真机证据 | 本地 job 明确前缀 `loomq-local-`，证据文档不申报真机 |
