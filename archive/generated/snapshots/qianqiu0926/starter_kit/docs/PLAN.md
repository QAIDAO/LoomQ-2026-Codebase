# LoomQ 完整交付规划与验收矩阵

## 目标

在官方固定接口内交付可复现、可解释、可验证的 L1/L2/L3 全栈方案，并申报工程、交互和量子 RISC-V Bonus。任何分数声明必须由代码、测试或可追溯外部证据支撑。

## 已完成阶段

1. **规则冻结**：逐项提取接口、门白名单、位序、评分阈值、L2 环境变量、L3 文法和归档规则。
2. **研究选型**：用 OpenQASM/QIR/tket/IBM QE 的 IR 分层思想确定单一中间层；用 CertiQ/Giallar/MorphQ 确定语义验证与变形测试；用 PICARD/执行反馈研究确定 L2 的受约束闭环。
3. **L1 实现**：严格 QASM parser、类型化 IR、三 emitter、状态向量模拟、结果 Schema、目标 IR 回译。
4. **L1 加固**：对抗审计发现“发射目标但执行源 IR”、相位盲区与单初态盲区；改为证明携带的目标回读执行。
5. **L2 实现与加固**：强制真实模型调用、JSON 计划、确定性电路构造/能力表筛选、解析与语义验证、一次有界修复；再加入原文硬约束投影与决策轨迹。
5. **L3 实现**：递归下降 parser、表达式 AST、嵌套分支、寄存器分配、确定性标签、临时状态清理。
6. **产品入口**：CLI 与本地 Web；新手任务、概率图、原始 IR、错误恢复、移动端和键盘可用性。
7. **Bonus**：RISC-V `custom-0` 两 profile 编码、`.word` 解码、量子执行与坍缩、`RY/RZ/CU1` 微弧度参数契约与误差界。
8. **验证**：公开评测、随机电路、目标回译、Hybrid 穷举、L2 本地兼容服务、浏览器桌面/移动实测。
9. **交付工程**：标准库零依赖、Docker、验证入口、研究/理论/限制/架构/证据文档、提交清单。

## 验收矩阵

| 风险 | 验收 oracle | 当前结果 |
|---|---|---|
| 门语义错误 | 已知态 + 逆门恒等式 | 通过 |
| emitter 丢门/错位/相位错 | 独立回译后比较规范轨迹、全态、测量映射与分布 | 80 随机电路 × 3 目标 + 2 类专用反例通过 |
| 运行绕过目标产物 | 结果显示执行对象与翻译收据 | 只执行独立回读目标，证书 SHA-256 可追溯 |
| shots/位序错误 | counts 和严格等于 shots；`x q[0]` 应得 `001` | 通过 |
| L2 绕过模型 | 本地 HTTP 兼容端点记录真实请求 | 1 次调用通过 |
| L2 模型输出非法 | 严格 JSON/QASM parser + 有界反馈 | 非 JSON 修复测试通过 |
| L2 后端幻觉 | 只从官方 JSON 确定性筛选 | 错误模型建议被覆盖 |
| L2 遗漏/矛盾用户硬约束 | 原文受保护约束投影 | 敌意付费 QPU 计划被免费免登录模拟器条件覆写 |
| Hybrid 打表 | 随机常量、嵌套分支、全测量组合 | 80 × 4 通过 |
| 自定义 opcode 只是注释 | 32 位 encode/decode + `.word` 执行 | 8 离散 + 3 参数 opcode 往返通过 |
| 参数门量化不可控 | 角度量化界 + 端到端态距离 | 0.5 μrad 角度界与组合误差界通过 |
| 量子测量实现错误 | Bell 多种 seed 只允许相关结果 | 100 seed 通过 |
| UI 只在桌面可用 | 1280px 与 390px 浏览器实测 | 无溢出、无控制台错误 |
| 归档不可复现 | `python3 verify_submission.py` / Docker | 命令已提供 |

## 外部依赖项
