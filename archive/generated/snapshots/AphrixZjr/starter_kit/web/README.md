# LoomQ 引导式量子实验

这是 L2 交互体验与“新手引导和视觉叙事”Bonus 的单场景产品入口。它不改变 `adapter.agent_chat()` 的客观评分契约；Web 层使用现有 parser、参考模拟器与后端能力表提供确定性事实。

## 一条命令启动

推荐在 `starter_kit/` 目录使用统一容器环境：

```bash
docker compose up --build
```

这会一次构建 L1、L2、L3 和 Bonus，并在 <http://127.0.0.1:8765>
启动界面。容器已包含界面可连接的 SpinQit、pyQPanda 和 AWS Braket 三个
L1 本地后端；`GET /api/health` 的 `l1_backends` 字段会报告连接状态。

不使用容器时，也可在完整安装 `requirements.txt` 的 Python 3.10 环境运行：

在 `starter_kit/` 中运行：

```bash
python web/server.py
```

浏览器打开 <http://127.0.0.1:8765>。正式评测注入 `LOOMQ_LLM_*` 时，八阶段 Bell 引导由 Agent 对话推进；自由工作台、本地运行和预设阶段回退不需要云账号或真实量子后端。自由问答和非预设 Agent 修改仍需要可用模型。

## 自由工作台与可选引导

页面默认是完整可用的工作台：电路、QASM 验证、运行结果和后端选择都在对应视窗中，不受实验模式或阶段锁定。需要教学时，点击“开始 Bell 引导”显示只属于 Bell 实验的八阶段路径；退出后不会丢失实验内容。

五分钟 Bell 路径：

1. 开始 Bell 引导，点击“填入本阶段指令”，焦点会进入 Agent 对话框；确认后发送。模型可用时，Agent 调用唯一允许的确定性阶段工具并根据实际结果解释；按钮本身不会修改实验。
2. 在运行前记录自己的预测；预测不计分。
3. 查看语法、静态结构、完整测量映射和受控 Bell/GHZ 目标语义验证，随后在本地参考模拟器生成 1024 条教学计数。
4. 对照柱状图与等价数据表，观察主要 `00/11` 分布。
5. 阅读结论边界：单一 Z 基测量显示相关性，但不能独立认证纠缠。
6. 继续探索可删除 CX，并用“撤销”恢复。

全流程在一个 URL 和一个 `ExperimentSession` 中完成。刷新会从当前服务进程恢复会话；停止服务会清除内存会话，且不写入个人数据。

## 三项现场任务

- Bell 黄金路径：完成八阶段实验，解释 H、CX、采样结果与结论边界。
- QASM 恢复：在 QASM 视窗插入缺分号示例，检查、预览 diff、应用安全修复，再撤销。
- 后端选择：在“运行位置”中选择 LoomQ 内置执行器或已安装的 SpinQit、pyQPanda、AWS Braket 本地模拟器；缺少的 SDK 会显示具体原因，不阻断内置执行器运行。
- 真机证据复盘：在“真机复盘”中比较仓库已归档的 Bell/GHZ-3 Ideal、SpinQ 和 OriginQ 计数、主峰与泄漏；该视图不会访问云端或创建任务。

## Agent 对话

底部 Agent 入口从首次加载起即可输入，并明确显示“已配置”“未配置”“本地预置回退”或请求失败。模型未配置、连接失败或响应无效时，只有未经修改、且与当前 Bell 阶段完全一致的界面指令可以触发回退：服务端执行同一个确定性阶段工具，并显示随代码发布的固定回复。未配置时正文和状态栏标注“未调用模型”；已经尝试模型但连接或响应失败时改为“回复非模型生成”，并通过 `model_attempted=true`、`model_generated=false` 保留事实边界。自由问答、改写后的指令和未来阶段指令不会命中该回退。

配置 `LOOMQ_LLM_BASE_URL`、`LOOMQ_LLM_API_KEY` 和 `LOOMQ_LLM_MODEL` 后，一般问题统一使用模型的自由文本回答，包括概念问答、当前电路、验证与运行结果解释。请求会携带最近对话以及当前 QASM、revision、目标、执行状态、所选后端、验证和运行结果。用户明确授权后，模型可调用运行、验证、设置目标、撤销和重做工具，工具结果会同步回工作台并交给模型继续回答。生成/修复 QASM 或选择后端仍使用结构化提案协议；提案经本地验证并显示摘要/diff，只有 `safe_to_apply=true` 时用户才能确认，服务端也会拒绝结构验证失败的提案；过期提案会被 revision 检查拒绝。

测量来源或经典目标重复会令结构验证失败，界面与服务端都禁止运行。目标语义不一致与结构危险分开处理：前者仍可作为探索电路运行，但结果会固定显示“本次运行不支持当前目标”，避免把计数误当成目标实现证据。

Bell 引导的八个阶段各有一条预设指令。用户每阶段主动点击按钮才会把指令填入并聚焦对话框，发送后才可能改变实验。有模型时，阶段专用系统提示约束模型只能调用一次当前工具，回答必须根据工具结果；模型不可用时返回固定、可核验的预置解释。如果工具已执行而模型只在生成解释时断线，回退只补回复，不会再次推进。本地阶段工具自身失败则返回 `local_tool_error`，不回退、不重试，也不伪装成模型故障。

每个会话用独立锁和只增不减的 `workbench_revision` 保护阶段提交。模型调用前捕获当前阶段与 revision，模型等待期间若 QASM、目标、后端、运行状态或撤销/重做发生变化，旧指令会以 stale conflict 结束；两个并发的同阶段指令也只有一个能提交。

这一取舍刻意保留单一的 Agent 交互焦点，不再为断网兜底增加一条平行的直接操作路径。代价是离线解释不具备实时适应性，也不能回答自由问题；收益是外部模型故障不会中断教学演示，同时来源边界始终可见。

## 键盘与无障碍

- `Tab` 顺着目标、路径、指导动作、电路、QASM 和证据移动，焦点始终可见。
- 电路提供完整文本描述；计数图提供 `aria-label` 和逐项一致的数据表。
- 状态同时使用图标、文字和边框，不只依赖颜色。
- “减少动态效果”可显式启用，且尊重系统 `prefers-reduced-motion`。
- 默认使用浅蓝–浅粉–白色主题；“色觉辅助”可切换到蓝–橙高区分配色。两个无障碍开关都有文字状态、`aria-pressed` 和本地持久化。
- QASM 自动修改先展示 diff；错误保留最后有效电路；修改可撤销/重做。
- 页面允许窄屏和高缩放下的纵向滚动；验收覆盖 1366×768、1280×720、1024 宽和 200% 缩放，不依赖固定 1100px 最小宽度。

## 验证

```bash
python -m unittest tests.test_l2_web tests.test_l2_audit_regressions -v
python -m unittest discover -s tests -v
```

`tests.test_l2_web` 与 `tests.test_l2_audit_regressions` 覆盖无模型八阶段黄金路径、自由工作台、目标语义与测量映射、科学文案、无效 QASM 恢复、revision 防竞态、并发同阶段提交、本地工具失败不重试、不可变运行快照、后端边界、提案确认协议、响应式无障碍契约和 HTTP 会话恢复。

可选的四视口机器检查需要先启动 Web，再以临时 profile 启动支持 CDP 的 Chromium/Edge：

```bash
msedge --headless=new --remote-debugging-port=9333 \
  --user-data-dir=<TEMP_PROFILE> http://127.0.0.1:8765/
node browser_responsive_check.mjs
node browser_agent_flow_check.mjs
```

第二个脚本需让服务保持无 `LOOMQ_LLM_*` 配置；它完成八次 Agent 发送，并验证按钮只填入和聚焦、验证先于运行、结果表和结论边界可见、探索阶段删除 CX、撤销恢复 CX，以及全过程显式本地预置回退。

Linux 可把 `msedge` 换成 `chromium`；不要复用含登录信息的日常浏览器 profile。脚本只连接本地 `127.0.0.1:9333`，输出 JSON 到标准输出，不自行下载浏览器或写证据文件。
