    1. 登录推荐平台，并根据平台当前的任务提交流程创建量子任务。
      2. 
              
    2. 在“电路代码”中查看标准 OpenQASM 2.0 与所选后端的 adapter 代码。
      3. 
              
    3. 按照平台当前支持的输入格式使用该线路，并选择推荐的真实硬件。
      4. 
              
    4. 设置本任务所需的 shots，提交后等待真机结果。
      5.
