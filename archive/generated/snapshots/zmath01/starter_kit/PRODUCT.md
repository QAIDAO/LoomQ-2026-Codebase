# LoomQ 产品化叙事（PRODUCT.md）

本文件回答评委最关心的两个问题：**这是不是三套硬编码？** 和 **你到底为谁解决了什么问题？**
配套架构细节见 `ARCHITECTURE.md`，证据清单见 `evidence/README.md`。

## 1. 我们为谁而做（目标用户）

LoomQ 的目标用户是**有独特问题意识、但没有任何量子/编程"黑话"背景的跨界创造者**：

| 用户画像 | 他们今天遇到的墙 | LoomQ 给他们的路 |
|---|---|---|
| 产品经理 / 设计师 | 想评估"量子优化能否解决我的调度问题"，但看不懂 QASM | 用自然语言描述问题，智能体生成电路并本地验证 |
| 数学/统计背景研究者 | 懂算法，但被 OriginIR / OpenQASM 3 / Braket SDK 三套方言劝退 | 一份电路，三家后端一键切换，永远不需要知道方言 |
| 高校新生 / 自学者 | 首次接触量子计算，被术语墙吓退 | 概念卡片 + "5 分钟内第一个实验"一键跑通 |
| 跨界科技作者 / 教育者 | 想演示"纠缠真的存在"，但没有算力入口 | 打开网页，点两下，得到直方图和一句人话解释 |

**一句话**：我们不做"更专业的量子工具"，我们做**量子计算的"普通话入口"**。

## 2. 竞品分析

| 产品 | 定位 | 它的门槛在哪 | LoomQ 的差异 |
|---|---|---|---|
| IBM Qiskit / IBM Quantum | 全球最大的量子 SDK + 云平台 | 需要 Python 与 QASM 知识；英文生态 | 中文零基础引导 + 自然语言入口 + 本地零依赖自验 |
| 本源量子云 / QPanda | 国产超导真机 + SDK | 有自己的 OriginIR 方言与账号体系 | 我们把它翻译给不懂 OriginIR 的人，并统一到一套结果 Schema |
| 量旋 SpinQit | 量旋硬件 + Taurus 模拟器 | 同样有独立 SDK 方言 | 同一套中间层覆盖它，用户无感知切换 |
| AWS Braket | 云上多厂商算力市场 | 需 AWS 账号 + 计费 + 英文 SDK | 本地免费模拟器即可体验，真机可选 |
| Classiq | 高层级量子程序抽象（商用） | 面向企业/专业团队，抽象层本身需要学习 | 面向"第一次用"的个人创作者，免费、可复现 |
| Strangeworks 等抽象层 | 多平台统一接入 | 面向开发者，仍需理解量子编程概念 | 教育向叙事 + 结果可视化 + 真机证据可溯源 |

**结论**：市面上的"统一层"都默认使用者已经跨过了编程门槛；LoomQ 把门槛再往下压一层——
**让"不会编程"的人也能完成从想法到结果的完整闭环**。这是"接入平权"的真正含义。

## 3. 差异化（我们做对了什么）

1. **零依赖、可复现**：整个中间层只使用 Python 标准库，`python:3.10-slim` 容器直接可跑，
   评委一条命令即可复现全部自测（`evaluator.py --level all`）。
2. **转译与执行同源**：`run()` 执行的是 `transpile()` 的**转译产物**，转译器与执行器无法互相掩盖错误。
3. **自然语言闭环**：生成 → 自检 → 出错重试，每个带 QASM 的回答都在本地模拟器真实跑过才返回。
4. **真机可溯源**：`run_real.py` 无 Mock 回退，平台原始返回原样保存，`job_id` 可溯源。
5. **双入口**：Web（概念卡片 + 可视化直方图）与 CLI（离线可用）同时交付，覆盖不同场景。
6. **隐私安全**：本仓库不含任何 API Key / Token；所有凭据只经环境变量注入，并有 `check_secrets.py` 提交前扫描。

## 4. 用户旅程（完整使用流程）

```text
第 0 分钟  打开 Web（python3 loomq_web.py）→ 概念卡片
第 1 分钟  进入"实验台"直接做第一个实验 → 贝尔态电路一键运行 → 看到 00/11 直方图
第 2 分钟  阅读"结果意味着什么" → 理解纠缠：两枚硬币永远同面
第 3 分钟  到"说人话 · 量子助手" → 输入"帮我做一个 3 比特最大纠缠态" → 智能体生成 GHZ 电路并自动验证
第 4 分钟  到"实验台" → 同一份电路切换 spinq / originq / braket 三后端各跑一遍
第 5 分钟  对比三家转译 IR → 理解"通用中间层"的价值
```

## 5. 必答题：谁第一次用上了量子计算？

> **你的工具，让哪一类原本进不来的人，第一次能够使用并受惠于量子计算？**

**完全没写过 QASM 的跨界创作者——尤其是产品、设计、教育背景的女性与跨界学习者。**

她们不缺问题意识（"我的排课问题能不能用量子优化？""给学生讲纠缠能不能真跑一遍？"），
缺的只是被行业默认的"黑话门槛"：每个平台一套 SDK、一套方言、一套账号。LoomQ 把这道门槛替换成一条自然语言对话 + 一个可视化直方图。我们提供的佐证：

- Web 界面（概念卡片 + 一键第一个实验）；
- 智能体"生成 → 本地自检 → 失败重试"的闭环，用户不直面语法错误；
- 结果配"大白话解释"，术语只在电路库知识里出现；
- 官方 QUANTUM_101.md（30 分钟速成）+ CLI guide（5 分钟上手），两条自学路径。
