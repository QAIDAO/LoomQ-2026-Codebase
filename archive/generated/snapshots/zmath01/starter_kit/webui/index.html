量子计算入门

🎲
量子比特

经典比特非 0 即 1，量子比特可处于 0 与 1 的线性叠加态。

🌀
叠加

H 门使比特进入 0 和 1 的概率幅组合，测量前状态未定。

🤝
纠缠

多比特形成不可分割的整体状态；测其一，其余瞬间关联确定。

📏
测量

测量导致叠加态随机坍缩为 0 或 1；需多次采样以统计概率分布。
