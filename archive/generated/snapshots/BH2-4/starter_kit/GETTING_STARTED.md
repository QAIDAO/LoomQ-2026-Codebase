# LoomQ 零基础入门：5 分钟跑出你人生第一个量子实验

不需要任何量子物理基础，不需要安装任何第三方库（纯 Python 标准库）。
跟着做就行。

## 第 1 步（30 秒）：看到量子纠缠

```bash
python3 starter_kit/chat.py --demo
```

你会看到一个 3 比特电路的测量直方图：只有 `000` 和 `111` 出现，各占一半。
这就是**纠缠**——三个量子比特像约好了一样，永远一起翻 0 或一起翻 1。

## 第 2 步（3 分钟）：让 AI 助手听懂你的大白话

对话功能需要一个 OpenAI 兼容的模型服务（评测时由组委会注入，本地调试可自备
DeepSeek Key）。配置三个环境变量：

```bash
export LOOMQ_LLM_BASE_URL=https://api.deepseek.com   # 或任何兼容服务
export LOOMQ_LLM_API_KEY=你的Key
export LOOMQ_LLM_MODEL=deepseek-v4-flash
```

然后开始对话：

```bash
python3 starter_kit/chat.py
```

试试这些话（怎么口语化都行）：
- `生成一个 3 比特 GHZ 态并测量`
- `来个贝尔态，两比特`
- `我要 4 比特的均匀叠加`
- `我想跑贝尔态但代码报错了：H q[0]; CX q[0] q[1]`
- `15 比特、零排队、免费，选哪个平台？`

助手每次生成电路后都会**自动**在本地模拟器上跑 4096 次并画出直方图、
给出通俗解读——你不需要懂任何一行代码。

## 第 3 步（1 分钟）：确认一切正常

```bash
python3 starter_kit/chat.py --doctor    # 环境自检
python3 starter_kit/evaluator.py        # 公开契约自测（应全 PASS）
```

## 三句话理解刚才发生了什么（量子概念速览）

1. **量子比特（qubit）**：普通比特是 0 或 1；量子比特可以"同时"是 0 和 1，
   这种同时状态叫**叠加**。`H` 门就是"造叠加"的开关。
2. **纠缠**：让多个量子比特的命运绑在一起——测量一个，其他的瞬间确定。
   `CX` 门负责"绑定"。你在直方图里看到的 `000`/`111` 各半，就是纠缠的铁证。
3. **测量**：叠加是脆弱的，一看就塌。量子程序的输出就是"塌缩统计"——
   跑很多次、数每种结果出现的次数，这就是直方图。哪些结果出现得多，
   取决于电路如何"摆弄"概率。

更系统的入门材料见官方科普文档 [`QUANTUM_101.md`](QUANTUM_101.md)。

## 出错了怎么办（错误自救表）

| 现象 | 原因 | 自救 |
|---|---|---|
| `missing required LoomQ L2 environment variable(s)` | 环境变量没配 | 回到第 2 步；Key 只放环境变量，绝不写进文件 |
| `LoomQ L2 API returned HTTP 401` | Key 无效/过期 | 换有效 Key；错误信息不会泄露你的 Key |
| `LoomQ L2 API is unreachable` | 网络或地址错误 | 检查 `LOOMQ_LLM_BASE_URL` 是否能访问 |
| 助手偶尔答非所问 | 大模型偶发 | 换个措辞再问一次；生成类问题重试即恢复 |
| 只想离线体验 | 没有模型也能玩 | `--demo` 随时可用；模拟器纯本地零依赖 |
