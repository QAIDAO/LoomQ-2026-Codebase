# LoomQ 量子 RISC-V 扩展指令集规格（L3 Bonus · 规格 ①）

版本：1.1 · 团队：BH2-4 · 本文档、实现与端到端测试构成 Bonus 申报三件套。

## 1. 设计目标

在官方 `TinyRISCVEmulator` 的 7 条经典指令（`li add sub addi beq bne j`）之上，
新增 **5 条量子扩展指令**，使量子操作成为 ISA 的一等公民——量子电路不再
"旁路"于经典控制流之外，而是与经典指令在同一条执行链路上顺序执行。
这正是官方 Q&A 指定的"方向 1"：指令编码实际进入可运行、可验证的执行链路。

v1.1 变更：新增 `QP` 相位门指令（π/4 档位制），门集自 {H, X, CX} 扩为
**{H, T, CX} 通用门集**；`QMS` 增补平局容差语义（见 §2）。

## 2. 指令集总表

| 助记符 | 汇编格式 | 操作数 | 语义 |
|---|---|---|---|
| `QH` | `qh qi` | qi：量子比特号（立即数） | 对 q[qi] 施加 Hadamard 门 |
| `QX` | `qx qi` | 同上 | 对 q[qi] 施加 Pauli-X 门 |
| `QCX` | `qcx qc, qt` | 控制/目标比特号 | 施加受控非门 CX(qc→qt) |
| `QMS` | `qms qi, rd` | rd：通用寄存器 | 测量 q[qi]，读数写入 rd，并坍缩内部状态 |
| `QP` | `qp qi, k` | k：相位档位 0–7 | 对 q[qi] 施加 diag(1, e^{i·kπ/4}) |

源级映射：`t`→k=1、`s`→k=2、`z`→k=4、`sdg`→k=6、`tdg`→k=7；
`p(λ)/u1(λ)` 当 λ 为 π/4 整数倍时折算档位，否则显式报错（不静默丢语义）。
档位常数取 0,±1,±i,±(1±i)/√2 的**代数精确值**（不用 cmath.exp），
跨平台逐位一致。

测量规则（可复现性优先）：`QMS` 采用**确定性最大幅度读数**——
若 P(q[qi]=1) > 0.5 则读 1，否则读 0；随后将状态向量中与读数不一致的分量
清零并整体归一化（全宽度坍缩，维度不变，后续量子指令的比特下标仍有效）。
含相位门后状态向量为复数振幅，概率取 |振幅|²；**平局容差**：p1 落在
0.5±1e-9 视作精确对半，确定性读 0——该规则同时固化在实现与参考侧
（l3_selftest），杜绝两条实现路径的 1 ulp 浮点差在对半分布上分叉。

## 3. 指令编码（32 位，RISC-V 自定义扩展空间）

五条指令均落在 RISC-V 标准预留的 CUSTOM-0 opcode 空间（`opcode=0x0B`），
采用 R 型位域布局，`funct7` 区分量子操作：

```
 31        25 24    20 19    15 14 12 11     7 6      0
+------------+--------+--------+-------+---------+--------+
|  funct7    |  rs2   |  rs1   |funct3 |   rd    | opcode |
+------------+--------+--------+-------+---------+--------+
```

| 指令 | funct7 | rd | rs1 | rs2 | funct3 | 示例编码（hex） |
|---|---|---|---|---|---|---|
| `qh qi`     | 0x20 | 0  | qi  | 0  | 0x0 | `qh 0` → `0x4000_000B`（funct7=0x20<<25 \| qi<<15 \| 0x0B） |
| `qx qi`     | 0x21 | 0  | qi  | 0  | 0x0 | `qx 1` → `0x4200_800B` |
| `qcx qc,qt` | 0x22 | 0  | qc  | qt  | 0x0 | `qcx 0,1` → `0x4410_000B`（rs1=0, rs2=1） |
| `qms qi,rd` | 0x23 | rd | qi  | 0  | 0x0 | `qms 0,x10` → funct7=0x23, rd=10 → `0x4600_050B` |
| `qp qi,k`   | 0x24 | 0  | qi  | 0  | k   | `qp 0,1`（T 门）→ 0x24<<25 \| 1<<12 \| 0x0B = `0x4800_100B`；`qp 0,4`（Z 门）→ `0x4800_400B` |

（v1.1 勘误：v1.0 示例 hex 与位域公式不符，本列已全部按公式重算。）

量子比特号占 rs1（QCX 时目标在 rs2），寄存器目的占 rd（QMS 专用，其余为 0）。
funct3 对 QH/QX/QCX/QMS 恒为 0x0；**对 QP 复用为相位档位 k（0–7）**——
π/4 步进的 8 档相位正好装入 3 bit，无需新位域。编码仅占用 RISC-V 规范
明确保留给厂商扩展的 CUSTOM-0 空间，不与任何标准指令冲突；funct7
0x25–0x3F 预留给后续量子操作（如受控相位、任意角单比特旋转的立即数扩展）。

## 4. 与官方 7 指令的关系

- 扩展模拟器 `riscv_emulator_qext.py` 是官方模拟器的**超集**：官方 7 指令
  语义逐条保留（含 1000 步上限、x0 恒 0、无位宽回绕）。
- **主提交不受影响**：`compile_hybrid` 输出的汇编只使用官方 7 指令，
  可在官方原版模拟器上运行（这是 15 分主分的硬约束）。
- Bonus 通路：`qext_codegen.compile_hybrid_qext` 把量子部分编成 QH/QX/QCX/QMS/QP，
  经典部分仍是官方指令，混合程序在扩展模拟器上一次执行完成"量子演化 →
  测量读数进寄存器 → 经典分支控制"，实现量子-经典同链路闭环。

## 5. 端到端测试（测试 ③）

```bash
python3 starter_kit/riscv_emulator_qext.py   # 模拟器自测（Bell 关联性 + QP 恒等式）
python3 starter_kit/l3_selftest.py --bonus   # 200 个随机 Hybrid 用例全链路对拍
python3 starter_kit/l3_selftest.py --qp      # 200 个随机含相位门电路，振幅级对拍
```

判定方式：随机生成 Hybrid-QASM（量子门 + 测量 + 嵌套经典控制，含 t/s/z/
sdg/tdg 相位门与干涉叠层），编译为混合程序在扩展模拟器执行；同时用状态
向量模拟器独立计算各比特的确定性测量值，喂给经典参考解释器——两者全部
寄存器终态必须一致（当前 0 失配）。`--qp` 套件更强：无测量电路的**终态
振幅**逐项对拍独立状态向量实现，容差 1e-9（当前 0 失配）。

## 5b. 确定性测量的设计依据

`QMS` 不采样物理随机数，而是取最大幅度侧读数，理由有三：

1. **可验证性**：端到端对拍要求"同一程序、唯一正确终态"。物理采样下
   终态是随机变量，只能做统计断言；确定性读数让 200×全部注入组合可以
   逐寄存器硬等式比对。
2. **可复现性**：同程序在任何机器、任何时刻跑出相同终态——与仓库
   "零依赖、离线、确定性"的整体口径一致（随机采样已在 L1 模拟器的
   8192-shots 统计口径中另做，两层各司其职）。
3. **语义无损**：读数后仍做全宽度坍缩 + 归一化，量子比特后续仍可参与
   干涉；对半分布（p1=0.5）以 1e-9 容差判平局、确定读 0（§2）。

## 5c. 时序模型路线图（预留，未实作）

eQASM 一系的核心贡献在周期级调度与门时序；本 ISA 的载体（官方 7 指令
教学模拟器）无时钟概念，故 v1.1 不引入时序语义，但编码空间已预留：

- funct3 对 QH/QX/QCX/QMS 恒为 0——可复用为**门时长档位**（如 3 bit ×
  基准周期），模拟器侧仅需加 cycle 计数器即可输出程序总时延估计；
- funct7 0x25–0x3F 预留受控相位/任意角旋转等，rs2 位域可承载第二比特
  号或立即数高位。

## 6. GPU 设备映射（展望，未实作）

QH/QX/QCX 天然映射为 GPU 内核：状态向量驻留显存，`qh qi` 即
`apply_h_kernel<<<…>>>(state, qi)`（逐对蝶形操作，coalesced 访问）；
`QMS` 对应两遍规约（p1 求和 + 掩码归一）。`QP` 为对角乘
（`state[idx] *= phase_table[k]`），映射最直接。该映射与 CUDA/OpenCL 的
量子模拟内核布局一致，规格层面即为"闭环到明确 GPU 设备指令集"预留接口。
