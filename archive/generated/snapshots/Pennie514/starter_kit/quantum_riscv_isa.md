# LoomQ Quantum RISC-V 扩展指令集规格 (LQ-Q Extension v1.0)

本文档定义 LoomQ 在 RISC-V `custom-0` opcode 空间上设计的量子扩展指令集，
使量子门操作成为 RISC-V 指令流中的一等公民，与经典控制流在同一条流水线上顺序执行。

- **指令编码规格**：本文档
- **模拟器扩展实现**：[quantum_riscv_emulator.py](quantum_riscv_emulator.py)（fork 官方 `riscv_emulator.py`）
- **端到端测试**：`python3 test_quantum_riscv.py`

---

## 1. 设计动机

官方 `riscv_emulator.py` 只能执行经典寄存器与分支指令，量子部分需由外部宿主驱动。
这意味着「测量 → 分支 → 再施加量子门」这类**中路测量反馈**（mid-circuit measurement
feedback）必须跨两个运行时来回搬状态。

LQ-Q 扩展把量子操作编码进指令流，使下列程序成为**单一指令序列**：

```asm
qinit   2               # 分配 2 个量子比特
qgate   h, 0            # q[0] 进入叠加态
qmeas   x10, 0          # 测量 q[0]，经典结果落入 x10
bne     x10, x0, RESET  # 若测得 1，则翻转回 |0>
j       DONE
RESET:
qgate   x, 0            # 条件量子门：由经典分支驱动
DONE:
qgate2  cx, 0, 1        # 纠缠
qmeas   x11, 1
```

量子态与经典寄存器共享同一个执行上下文，无需宿主介入。

## 2. 编码格式

全部量子指令使用 RISC-V **R-type** 布局与 `custom-0` opcode，因此不与任何标准
RV32I/RV64I 指令冲突。

```
 31        25 24     20 19     15 14   12 11      7 6           0
┌────────────┬─────────┬─────────┬───────┬─────────┬─────────────┐
│   funct7   │   rs2   │   rs1   │funct3 │   rd    │   opcode    │
│   7 bits   │  5 bits │  5 bits │3 bits │ 5 bits  │   7 bits    │
└────────────┴─────────┴─────────┴───────┴─────────┴─────────────┘
```

| 字段 | 宽度 | LQ-Q 用途 |
|---|---:|---|
| `opcode` | 7 | 固定 `0b0001011` (0x0B, RISC-V 保留的 custom-0) |
| `funct3` | 3 | **门类别**（见 §3） |
| `funct7` | 7 | 类别内的**具体门编号**，或第三比特索引 |
| `rs1` | 5 | 第一量子比特索引（**立即数直接编码在寄存器字段**） |
| `rs2` | 5 | 第二量子比特索引 |
| `rd` | 5 | 测量结果写入的经典寄存器 `x[rd]` |

> **设计决策**：`rs1`/`rs2` 字段承载**量子比特索引字面量**而非寄存器号。
> 5 bit 宽度恰好覆盖 0–31 号比特，与模拟器 32 个经典寄存器的规模对称，
> 且避免每次施加门都要先 `li` 一个索引到寄存器。唯一例外是 `qsetp`（§3.7），
> 它的 `rs1` 是真正的寄存器号，因为旋转角度需要运行时计算。

## 3. 指令类别 (funct3)

### 3.1 `funct3 = 0b000` — 单比特无参门 `qgate`

`qgate <gate>, <qubit>` — 对 `q[rs1]` 施加门，`funct7` 选门：

| funct7 | 门 | 汇编助记符 |
|---:|---|---|
| 0 | Hadamard | `qgate h, n` |
| 1 | Pauli-X | `qgate x, n` |
| 2 | S | `qgate s, n` |
| 3 | S† | `qgate sdg, n` |
| 4 | T | `qgate t, n` |
| 5 | T† | `qgate tdg, n` |

### 3.2 `funct3 = 0b001` — 单比特含参门 `qrot`

`qrot <gate>, <qubit>` — 旋转角取自内部参数寄存器 `QPARAM`（由 `qsetp` 设置）：

| funct7 | 门 |
|---:|---|
| 0 | RZ(QPARAM) |
| 1 | RY(QPARAM) |

### 3.3 `funct3 = 0b010` — 两比特门 `qgate2`

`qgate2 <gate>, <q1>, <q2>` — `rs1` 为控制位／第一操作数，`rs2` 为目标位：

| funct7 | 门 | 语义 |
|---:|---|---|
| 0 | CNOT | control=`rs1`, target=`rs2` |
| 1 | SWAP | 交换 `rs1` 与 `rs2` |
| 2 | CU1(QPARAM) | control=`rs1`, target=`rs2` |

### 3.4 `funct3 = 0b011` — 三比特门 `qccx`

`qccx <c1>, <c2>, <target>` — Toffoli。控制位为 `rs1`、`rs2`，
**目标位编码在 `funct7` 低 5 位**（白名单中仅 ccx 一个三比特门，故 funct7 无需再区分门种）。

### 3.5 `funct3 = 0b100` — 测量 `qmeas`

`qmeas x<rd>, <qubit>` — 测量 `q[rs1]`，按 Born 规则采样，**波函数塌缩**，
经典结果（0 或 1）写入 `x[rd]`。这是量子域向经典域的唯一数据通路。

### 3.6 `funct3 = 0b101` — 初始化 `qinit`

`qinit <n>` — 分配 `rs1` 个量子比特，态矢初始化为 |0…0⟩。须在任何量子门之前执行。

### 3.7 `funct3 = 0b110` — 设置参数 `qsetp`

`qsetp x<rs1>` — 将经典寄存器 `x[rs1]` 的值读入 `QPARAM`，单位为**毫弧度**
（milliradian, 1/1000 rad）。

> **设计决策**：角度用整数毫弧度而非浮点，以便完全复用 RISC-V 整数寄存器与
> `li`/`add`/`addi` 算术——经典代码可以运行时计算旋转角。
> 实际弧度值为 `QPARAM / 1000.0`。例如 π/2 ≈ 1571 毫弧度。

## 4. 编码示例

`qgate2 cx, 0, 1`（CNOT，control=q[0], target=q[1]）：

| 字段 | 值 | 二进制 |
|---|---:|---|
| funct7 | 0 (CNOT) | `0000000` |
| rs2 | 1 (target) | `00001` |
| rs1 | 0 (control) | `00000` |
| funct3 | 2 (两比特类) | `010` |
| rd | 0 (未用) | `00000` |
| opcode | 0x0B | `0001011` |

完整 32 位字：`0000000 00001 00000 010 00000 0001011` = `0x0010200B`

`qmeas x10, 0`（测量 q[0] 到 x10）：

| 字段 | 值 | 二进制 |
|---|---:|---|
| funct7 | 0 | `0000000` |
| rs2 | 0 | `00000` |
| rs1 | 0 (被测比特) | `00000` |
| funct3 | 4 (测量类) | `100` |
| rd | 10 | `01010` |
| opcode | 0x0B | `0001011` |

完整 32 位字：`0000000 00000 00000 100 01010 0001011` = `0x0000450B`

## 5. 执行模型

模拟器维护三份状态：

1. **经典寄存器** `x0..x31`（`x0` 恒为 0）——继承官方模拟器语义
2. **量子态矢** `psi`，长度 2^n 的复数数组，小端约定（`q[0]` 为最低位）
3. **参数寄存器** `QPARAM`，整数毫弧度

指令按 `pc` 顺序执行；量子指令推进量子态，经典指令推进经典寄存器，
`qmeas` 是二者之间的桥。分支指令读经典寄存器，因此**量子测量结果可以直接驱动控制流**。

测量采用真实 Born 规则采样并令态矢塌缩、重新归一化，不是「先算完分布再抽样」——
这保证中路测量后续门作用在正确的塌缩态上。

## 6. 与官方模拟器的兼容性

`QuantumRISCVEmulator` 继承 `TinyRISCVEmulator`，全部 7 条原有指令
（`li, add, sub, addi, beq, bne, j`）语义不变，纯经典程序行为完全一致——
官方 L3 测试可以直接在扩展模拟器上跑通。量子指令是**纯增量**。

验证：`python3 test_quantum_riscv.py` 的 §1 用例即为官方模拟器自带的经典程序回归。
