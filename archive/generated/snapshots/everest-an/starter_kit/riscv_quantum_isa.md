# 自定义量子 RISC-V 扩展指令 · 编码规格 v1.0

> LoomQ Bonus：把量子操作编码进 RISC-V ISA，让量子门与经典控制流
> 在同一条指令流中执行。实现：`starter_kit/riscv_emulator_quantum.py`
> （对官方 `riscv_emulator.py` 的 fork 扩展）；端到端测试：
> `starter_kit/selftest_quantum_isa.py`。

## 1. 设计动机

官方模拟器只覆盖经典子集（`li/add/sub/addi/beq/bne/j`）。本扩展增加
量子协处理器语义：**量子门修改一个虚拟量子寄存器堆（qubit file），
测量指令把测量结果写回标准经典寄存器 x10+k**——与赛题 L3 的
"测量位 c[k] 映射到 x10+k" 约定完全一致，因此量子-经典混合程序可以
在一条指令流里自然表达：

```asm
qinit 2          # 初始化 2 个量子比特到 |00>
qh q0            # H q0
qcx q0, q1       # CX q0 -> q1      （现在 |00> 与 |11> 各 1/2）
qm q0            # 测量 q0 → x10
qm q1            # 测量 q1 → x11
beq x10, x11, OK # 经典分支依赖量子测量结果！
li x1, 0
j END
OK:
li x1, 1
END:
```

## 2. 指令编码（32 位，小端，二进制编码见 §3）

| 位段 | 宽度 | 字段 | 含义 |
|---|---|---|---|
| `[31:28]` | 4 | `opcode` | 量子扩展主码，固定 `0xF`（1111），与基础指令不冲突 |
| `[27:24]` | 4 | `qop` | 量子操作码（见下表） |
| `[23:20]` | 4 | `qa` | 第一个量子比特索引（0–7） |
| `[19:16]` | 4 | `qb` | 第二个量子比特索引（单比特门忽略） |
| `[15:0]` | 16 | `imm16` | 有符号定点参数（Q14 格式，见 §4）；无参门填 0 |

### 2.1 量子操作码（qop）

| qop | 助记符 | 语义 | 参数 |
|---|---|---|---|
| `0000` | `qh` | Hadamard 门 H | — |
| `0001` | `qx` | Pauli-X 门 X | — |
| `0010` | `qrz` | 相位旋转 RZ(θ) | `imm16` = θ |
| `0011` | `qry` | 绕 Y 旋转 RY(θ) | `imm16` = θ |
| `0100` | `qcx` | 受控非 CNOT(qa → qb) | — |
| `0101` | `qswap` | 交换 SWAP(qa, qb) | — |
| `0110` | `qm` | 测量 qa，结果写 x10+qa | — |
| `0111` | `qinit` | 初始化 n=qa+1 个比特为 \|0...0> | — |

保留 `1000–1111` 备扩展（后续可加 qccx / qcu1 / qs / qt 等）。

### 2.2 汇编助记符

```
qh  q<k>                 # 单比特无参
qx  q<k>
qrz q<k>, <θ>            # θ 为十进制浮点，汇编器编码为 Q14 定点
qry q<k>, <θ>
qcx q<a>, q<b>           # 两比特
qswap q<a>, q<b>
qm  q<k>                 # 测量写 x10+k
qinit <n>                # n ∈ 1..8
```

## 3. 二进制编码示例

`qrz q3, 1.5707963267948966`（= π/2）：

```
opcode=1111  qop=0010  qa=0011  qb=0000  imm16=0110010010000111
 31        28 27    24 23   20 19   16 15                   0
```

- π/2 的 Q14 定点：`round(1.5707963267948966 × 2^14) = 25736 = 0x6488`
  → 二进制 `0110 0100 1000 1000`（上表为示意，实际以编码器输出为准）。
- 编码器/解码器见 `riscv_emulator_quantum.py` 的 `encode_qinst` / `decode_qinst`。

## 4. 定点参数格式（Q14）

- `imm16` 为有符号 16 位定点，小数位 14：`θ = imm16 / 2^14`。
- 表示范围 ≈ ±1.99994，分辨率 ≈ 6.1×10⁻⁵（rad）——对量子旋转门
  的精度需求（π/4 ≈ 0.7854）绰绰有余。
- 汇编器负责浮点 → 定点的舍入；模拟器负责定点 → 浮点的还原。

## 5. 模拟器执行语义

- 量子状态：幅值数组 `|ψ⟩ ∈ C^(2^n)`，Qiskit 位序（index 的 bit k = qubit k）。
- `qh/qx/qrz/qry/qcx/qswap`：就地更新状态向量（门矩阵与 `simulator.py`
  中 L1 中间层实现一致，保证跨层语义统一）。
- `qm qa`：按 Born 规则采样 qubit qa 的边缘分布，把结果写 `x10+qa`，
  **并投影坍缩**状态（后续量子门在坍缩后状态上继续作用）——
  这使"测量后条件执行"在单条指令流中成立。
- `qinit n`：重置量子寄存器堆为 |0...0>（幂等）。
- 未初始化就使用量子指令：等价于默认 n=0 状态 |·⟩（空态），测量恒 0；
  建议程序先 `qinit`。

## 6. 与赛题契约的衔接

- 测量写回位置 x10+k 与 L3 契约（c[k] → x10+k）一致；
- 门语义（H/X/RZ/RY/CNOT/SWAP）与 L1 12 门白名单子集一致，
  可用 `simulator.py` 交叉验证（测试见 `selftest_quantum_isa.py`）；
- 扩展完全向后兼容：不修改基础指令集，官方程序不经改动即可运行。

## 7. 端到端测试

`selftest_quantum_isa.py` 验证：

1. **贝尔态程序**：`qinit 2; qh q0; qcx q0,q1; qm q0; qm q1` × 多次运行，
   断言测量对始终为 (00, 11)，且统计比例 ≈ 1:1（±3σ 采样容差）；
2. **测量反馈分支**：测量结果驱动 `beq` 分支，终态寄存器随测量一致；
3. **旋转门精度**：`qry q0, π/2` 后测量，|1> 概率 ≈ 50%（Q14 舍入容差内）；
4. **编码器往返**：`encode → decode` 无损（定点舍入误差 ≤ 2⁻¹⁴）；
5. **经典子集回归**：官方示例程序在扩展模拟器中结果不变。
