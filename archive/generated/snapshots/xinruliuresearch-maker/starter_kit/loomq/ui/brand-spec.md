# LoomQ Pegasus · Local Workbench Brand Spec

This is an original project identity, not a derivative of SCI-Pegasus or a
vendor brand. It is intentionally self-contained so the workbench has no
network or CDN dependency.

## Core asset

- Primary mark: `static/mark.svg`
- Construction: three interleaved circuit paths, one measurement aperture
- Clear space: at least half the mark width
- Never recolor the mark to imply SpinQ, OriginQ, or AWS endorsement

## Palette

- Mineral ink: `#17201B`
- Field paper: `#F2F0E8`
- Work surface: `#E6E3D8`
- Spectral green: `#16725A`
- Cobalt data: `#275F9C`
- Oxide error: `#B94E32`
- Focus amber: `#D79A24`

## Type

- UI: `Aptos`, `Segoe UI`, `Microsoft YaHei`, system sans-serif
- Data/code: `Cascadia Mono`, `SFMono-Regular`, `Consolas`, monospace

## Signature detail

The left rail uses measurement ticks and explicit coordinate labels. Panels
share ruled baselines instead of floating rounded cards. No gradients, stock
illustrations, emoji navigation, glass effects, or external fonts/assets.

## Wording boundary

- Say: target dialect generated; LoomQ local reference simulator executed.
- Never imply a vendor SDK, cloud service, or QPU ran without a matching raw
  response, job ID, backend identity, and timestamp in evidence.
