量子概念速查新手可展开的 9 个术语 09 TERMS

本面板解释界面读数，不推断未测量的量子态。

Qubit
量子信息的线路单位；电路图的 q0、q1 表示它们的索引。
Gate
对指定 qubit 的操作；图中的门来自已准入的规范化 IR。
Measurement
把 qubit 的测量结果写入经典 bit，电路图标为 M 和 cN。
Shots
同一电路重复采样的次数；它不是门数。
Counts
实际观测到的比特串次数；count / shots 是样本频率，不是振幅。
Little-endian
较低索引的 c0 是最低有效位，在输出比特串中位于最右侧。
模拟器 vs 真机
本地参考模拟器计算数学模型；QPU 有物理噪声、排队和凭据。无硬件证据时不声称真机执行。
转译 vs 执行
转译生成 SpinQ / OriginIR / Braket 方言；执行才会产生 shots 和 counts。
PASSED
表示本地语法、往返语义和结果模式检查通过；不等于算法已被证明或 QPU 已运行。
