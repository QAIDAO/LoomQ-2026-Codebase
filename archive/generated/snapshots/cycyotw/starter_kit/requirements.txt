# LoomQ 提交依赖 · 精确锁定（赛题「可复现性要求」：第三方依赖必须精确锁定版本）
#
# 构建环境：Python 3.10（与 starter_kit/Dockerfile 的 python:3.10-slim 一致）
# 本清单由干净 venv 的 pip freeze 生成，开发机为 macOS 26 arm64 / Python 3.10.20。
#
# 两处刻意的固定，改动前请先读 starter_kit/docs/L1-人话卡片.md：
#
# 1. scipy==1.14.1
#    Python 3.10 能装的最高版是 1.15.3，但它的二进制在 macOS 27 上 dyld 拒绝加载
#    （__DATA/__thread_bss 为 zero-fill 但 offset 非零）。三个后端都要过 scipy，
#    会一起失败。逐版本实测 1.14.1 及更早均正常。
#
# 2. antlr4-python3-runtime==4.13.2
#    braket 的 OpenQASM 3 解析器要求 4.13.2；spinqit 0.2.4 要求 4.9.2，
#    两者互斥（antlr 4.10 把 serializedATN 从字符串改成整数数组，
#    版本不匹配时连 import 都会失败）。本提交选择 braket + originq 两个后端，
#    因此固定 4.13.2，并且不安装 spinqit。
#    transpile(qasm, 'spinq') 是纯文本转换，不需要 spinqit，不受影响。
