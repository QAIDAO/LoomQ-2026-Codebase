## 5. Parse the L3 classical mini-language and emit only supported RISC-V

**Files:**
- Modify: `starter_kit/loomq_l3.py`
- Test: `starter_kit/tests/l3/test_riscv_codegen.py`

**Steps:**

1. Add failing tests for `rN = integer`, assignments containing `+/-`, assignment chaining, `c[k]` mapping to x(10+k), both comparisons, `if/else`, nested `if`, and invalid register/operator syntax.
2. Implement a tokenizer with line/column errors for integer literals, `r1..r9`, `c[integer]`, punctuation and operators.
3. Implement a recursive-descent parser returning small immutable AST nodes: assignment, if, integer, register, measurement, binary arithmetic and comparison. The grammar has one arithmetic-precedence level and only comparisons in `if` conditions.
4. Implement a label allocator and code generator. Map `rN` to `xN`, `c[k]` to `x(10+k)`, and reserve x28-x31 as temporaries. Emit only `li`, `add`, `sub`, `addi`, `beq`, `bne`, `j`, and `LABEL:`.
5. Generate comparison branches with inverse conditions, then-body jump, else label, and end label. Copy right-hand results to the target without destroying sources; special-case literal arithmetic to use `addi` where appropriate.
6. Wire `adapter.compile_hybrid` to `loomq_l3.compile_hybrid` using the same package/direct import fallback as L2.
7. Run `python -m unittest starter_kit.tests.l3.test_riscv_codegen -v` until green.
