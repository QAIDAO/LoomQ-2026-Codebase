# Scientific museum workbench

画面像一件可以触摸的科学博物馆展项：有纸张质感、清晰标尺、路径和真实数据标签。重点对象必须有实体感和明确的运动因果；装饰只用于建立空间层次。

- 不使用紫蓝渐变文字、全屏霓虹、随机粒子和无限循环。
- 箭头长度与方向必须承担振幅/相位含义，不能只是装饰。
- 数据条从共同基线生长，数字与条形同步落定。
- 重要结论保持至少最后 25% 时长，给学习者阅读时间。
