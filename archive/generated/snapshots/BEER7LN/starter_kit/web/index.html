    LoomQ / Chapter 00

    量子计算，
    究竟改变了什么？

    从一个确定的 0 开始，看门操作如何改变状态、路径如何干涉，以及测量为何只留下一个结果。

    向下滚动↓

    01 / CLASSICAL BIT

    经典 bit 只有一个当前值。

    现在是 0。NOT 可以把它变为 1，但任一时刻，读到的值都是确定的。

    当前状态
    0
    读出结果
    一定得到 0

    02 / AMPLITUDES

    测量之前，0 和 1 各有一个振幅。

    这不是两个预先藏好的答案。振幅的大小影响测量概率，方向表示相位。

    路径 |0⟩
    振幅 α
    路径 |1⟩
    振幅 β

    03 / PHASE + INTERFERENCE

    路径相遇时，会增强，也会抵消。

    相位决定它们如何相加。同向增强，反向抵消；算法借此放大需要的结果。

    同相 · 相长 反相 · 相消

    04 / MEASUREMENT

    一次测量，一个答案。重复运行，形成分布。

    Bell 电路重复运行后，结果主要落在 00 和 11。每根柱子汇总的是多次独立测量。

    00 01 10 11
