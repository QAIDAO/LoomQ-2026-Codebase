# LoomQ 实现架构

## 面向谁

LoomQ 面向会描述实验目标、但不会手写量子汇编，也不了解不同量子云平台差异的
学生、教师和应用开发者。它要让这类原本被 QASM 语法、厂商 SDK、账号和排队规则
挡在门外的人，第一次能够用自然语言生成可验证的量子电路、看懂测量结果，并选择
实际可用的执行环境。

## 一次请求如何流动

1. `l2_cli.py` 接收自然语言，提供示例、连续输入和错误恢复。
2. `l2_agent.py` 让统一模型提取结构化目标；`llm_client.py` 只负责读取环境变量并
   调用 OpenAI-compatible 接口，不硬编码模型地址或凭证。
3. `l2/schema.py` 与 `l2/normalize.py` 清洗和校验输出；`parser.py` 把 QASM 转成共享
   电路 IR。
4. `l2/simulate.py`、`reference.py` 与 `verify.py` 在本地比较实际分布和目标分布。
   不合格结果最多重试三次；模型已经正确声明目标时，`synthesize.py` 可以确定性
   重建常见电路。
5. `l2/backends.py` 根据版本化能力表选择后端。L1 的三个 emitter/backend 模块把
   同一 IR 分别转换并运行于 SpinQ、OriginQ 和 Braket。
6. `l2_cli.py` 将通过检查的电路、counts 换算、概率和文本直方图一起展示给用户。

L3 与对话链路解耦：`l3_compiler.py` 从混合源码中分离量子操作，使用词法/语法分析
建立经典语句树，再把整数、`r1..r9`、`c[k]`、加减和分支降低到内置模拟器支持的
RISC-V 指令。测量位 `c[k]` 固定映射为 `x10+k`，便于评测器注入量子测量结果。

## 确定性与故障边界

- 模型只负责理解意图和提出候选；语法、门集、目标分布、后端硬约束和最终输出均由
  本地代码检查。
- 模型服务不可用时，CLI 明确指出需要检查的配置，不显示或记录 API Key。
- SpinQ 使用隔离虚拟环境，避免其依赖版本与 Qiskit/Braket 冲突。
- L3 不执行任意 Python 或 shell，只接受明确列出的有限语法，并对寄存器范围和尾随
  内容做拒绝式校验。

## AI 辅助开发说明

项目使用 AI 辅助代码评审、测试设计和部分实现草拟。所有进入提交的逻辑均由团队
结合赛题契约逐项审阅，并通过本地单元测试、量子分布验证、RISC-V 参考语义穷举与
公开 evaluator 复核。运行时的 AI 仅用于 L2 意图理解；评分关键的验证、选择、编译
与模拟路径是可阅读、可重复测试的确定性代码。

## 如何验证

- **L1**：公开 evaluator 对 Bell、GHZ3 电路在 SpinQ、OriginQ、Braket 三个平台的
  transpile 与 run 做保真度检查；evidence 另保存 SpinQ 与本源悟空 180 的真机 job、
  原始结果、实际电路和任务截图。
- **L2**：`tools/l2_selfcheck.py` 提供 12 个评测外自测变体，覆盖生成、纠错和后端
  选择。脚本只通过正式 `agent_chat` 入口请求结果，判定在本地完成：QASM 解析、无
  噪声模拟、目标分布保真度和规范后端 ID 集合。用例和期望值不被 adapter 导入，
  不参与运行时回答，也不是针对正式隐藏 prompt 的查表路径。
- **L3**：回归过程随机生成混合程序，穷举所有测量位注入组合，并与独立参考解释器
  逐寄存器比较；单元测试覆盖经典块前后量子操作、长表达式和 1000 步限制。量子
  RISC-V 扩展另对 32 位 custom-0 指令执行 round-trip 和非法字段拒绝测试。
- **封板检查**：`python3 -m pytest -q` 运行全部回归；`evaluator.py --level all` 生成
  根目录 `report.json`；`prepare_submission.py` 检查工作区、远端提交和必需文件。

## 已知限制

按比特下标描述目标态时（例如"q[1] 固定为 1"），模型偶尔会把位串写反——把 q[0]
当成最左位，而 LoomQ 约定最右位才是 c[0]。我们为此做了三件事：两处 system prompt
都给出带数字的位序范例；两个候选目标精确互为位串翻转时，判定为编码约定分歧而非语义
分歧，触发一次专门的位序裁决；裁决无法给出可用结论时保留生成侧结果，不让单次抽取
拥有否决权。

实测 14 个私有变体通过 13 个。剩下 1 个（tools/l2_selfcheck.py 的 C14）是模型在
那道二选一上表现出位置偏好，稳定选择第一个候选，因此裁决未能纠正生成侧的位序。
该路径不影响任何在位串翻转下对称的目标态（GHZ、W、均匀叠加、Bell、回文基态），
也完全不涉及 L1 与 L3。
