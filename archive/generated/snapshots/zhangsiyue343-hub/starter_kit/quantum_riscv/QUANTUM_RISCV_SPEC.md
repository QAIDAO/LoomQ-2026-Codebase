# 自定义量子 RISC-V 扩展指令规格 (LoomQ Quantum RISC-V Extension) v1.1

> 本扩展在 LoomQ 官方轻量 RISC-V 模拟器（`riscv_emulator.py`）之上，新增一组
> **自定义量子指令**，用标准 RISC-V 编码空间表达量子门操作，使经典-量子混合程序
> 可以在同一套指令流中执行。此即赛题 Bonus「自定义量子 RISC-V 扩展指令（+8）」的
> 交付物之一：指令编码规格。
>
> **v1.1 变更**：采用**指令字驱动的执行链路**——汇编文本被编码为 32 位机器码
> 指令字，执行时逐字解码（按 opcode/funct3/funct7 字段分派），使自定义 opcode
> 真正参与运行（主办方 Bonus 方向 1）。参数门 funct3 区段调整为 3/4/5，避免与
> R 型门的 funct3(0/1/2) 歧义；分支偏移按"指令索引"语义编码。

---

## 1. 设计原则

1. **复用 RISC-V 编码空间**：所有量子指令使用 RISC-V 保留给自定义扩展的
   `CUSTOM-0` opcode（`0b0001011` = `0x0B`），不影响标准指令 `li/add/sub/addi/beq/bne/j`。
2. **比特字段语义复用**：标准 R 型指令中 `rd/rs1/rs2` 是寄存器索引，本扩展把这三个
   5 位字段复用为**量子比特索引**（0–31），配合 `funct7`/`funct3` 编码门类型。
3. **参数门用立即数**：需要角度的门（`ry/rz/cu1`）使用 I 型立即数字段承载角度，
   以"π 的倍数"表示（与 qelib1 约定一致），避免浮点误差。
4. **测量指令**：把测量结果写入经典寄存器（`rd` 复用为经典寄存器索引），使量子结果
   能进入经典控制流（`beq/bne/j`）。
5. **指令字驱动**：`assemble()` 把助记符文本编码为 32 位机器码；`execute()` 对每个
   指令字调用 `decode_word()`，按 opcode/funct3/funct7 字段分派执行。opcode 真实参与
   运行，而非仅存于文档。

## 2. 指令编码总览

### 2.1 无参数门 —— 量子 R 型 (Quantum R-type)

```
 31        25 24     20 19     15 14    12 11      7 6       0
┌────────────┬─────────┬─────────┬────────┬─────────┬────────┐
│   funct7    │   qb     │   qa     │ funct3 │    qd    │ 0001011│
└────────────┴─────────┴─────────┴────────┴─────────┴────────┘
```

| 字段 | 位数 | 含义 |
|---|---|---|
| `funct7` | 7 | 门类型编码（见 §3） |
| `qb` (rs2) | 5 | 量子比特 b 索引（两/三比特门的第二个操作数） |
| `qa` (rs1) | 5 | 量子比特 a 索引（第一操作数） |
| `funct3` | 3 | 门变体/阶数（0=单比特，1=两比特，2=三比特） |
| `qd` (rd) | 5 | 量子比特 d / 测量目标经典寄存器索引 |
| `opcode` | 7 | `0b0001011` (CUSTOM-0) |

**汇编助记符**（模拟器接受）：

| 助记符 | 语义 | funct7 | funct3 | qa | qb | qd |
|---|---|---:|---:|---|---|---|
| `qh qa` | H 门 | 0x01 | 0 | qa | – | – |
| `qx qa` | X 门 | 0x02 | 0 | qa | – | – |
| `qs qa` | S 门 | 0x03 | 0 | qa | – | – |
| `qsdg qa` | S† 门 | 0x04 | 0 | qa | – | – |
| `qt qa` | T 门 | 0x05 | 0 | qa | – | – |
| `qtdg qa` | T† 门 | 0x06 | 0 | qa | – | – |
| `qcx qa, qb` | CNOT（控制 a，目标 b） | 0x08 | 1 | qa | qb | – |
| `qswap qa, qb` | SWAP | 0x09 | 1 | qa | qb | – |
| `qccx qa, qb, qd` | TOFFOLI（控制 a、b，目标 d） | 0x0A | 2 | qa | qb | qd |
| `qmeas qd, qa` | 测量 qa → 经典寄存器 x{qd} | 0x0B | 0 | qa | – | qd |

`qa/qb/qd` 字段为空（–）时编码为 0。

### 2.2 参数门 —— 量子 I 型 (Quantum I-type)

```
 31           20 19     15 14    12 11      7 6       0
┌────────────────┬─────────┬────────┬─────────┬────────┐
│   imm[11:0]     │   qa     │ funct3 │    qd    │ 0001011│
└────────────────┴─────────┴────────┴─────────┴────────┘
```

| 字段 | 位数 | 含义 |
|---|---|---|
| `imm[11:0]` | 12 | 角度 × 16（定标整数；例如 π/2 → 取整(π/2 × 16 / π) = 8） |
| `qa` (rs1) | 5 | 目标量子比特索引 |
| `funct3` | 3 | 门类型：`3`=`ry`，`4`=`rz`，`5`=`cu1` |
| `qd` (rd) | 5 | `cu1` 时的第二个比特索引（控制/目标），单比特门时为 0 |
| `opcode` | 7 | `0b0001011` (CUSTOM-0) |

> 参数门 funct3 使用 3/4/5，与 R 型门的 funct3（0/1/2）区分，解码时无歧义。

**角度编码**：`imm` 以"π 的倍数 ×16"定标存 12 位有符号整数。
解码公式：`θ = imm/16 × π`。
例：`ry(π/2)` → `imm = 8`；`ry(0.75π)` → `imm = 12`；`rz(−π/4)` → `imm = −4`。

| 助记符 | 语义 | funct3 | imm 单位 |
|---|---|---|---|
| `qry qa, imm16` | RY(θ)，θ = imm16/16·π | 3 | 1/16 π |
| `qrz qa, imm16` | RZ(θ)，θ = imm16/16·π | 4 | 1/16 π |
| `qcu1 qa, qb, imm16` | CU1(θ)，控制 a、目标 b | 5 | 1/16 π |

> 注：解码时 opcode=0x0B 且 funct3≥3 → 参数门（I 型布局，imm 在 [31:20]）；
> funct3<3 → R 型量子门（按 funct7 识别）。完全无歧义。

## 3. 门类型编码表 (funct7)

| funct7 | 门 | 备注 |
|---|---:|---|
| 0x01 | H | 阿达玛 |
| 0x02 | X | NOT |
| 0x03 | S | 相位 π/2 |
| 0x04 | SDG | 相位 −π/2 |
| 0x05 | T | 相位 π/4 |
| 0x06 | TDG | 相位 −π/4 |
| 0x07 | Z | 相位 π（预留） |
| 0x08 | CNOT | 两比特 |
| 0x09 | SWAP | 两比特 |
| 0x0A | TOFFOLI | 三比特 |
| 0x0B | MEASURE | 测量 → 经典寄存器 |

参数门不占用 funct7（复用 funct3 区分）。

## 4. 状态表示

- 模拟器维护一个 `2^n` 复振幅向量（n = `qinit n` 声明的量子比特数）。
- 量子指令直接作用于此向量；测量指令以 Born 规则采样并坍缩，把结果位写入
  `x{qd}`（与 L3 的 `c[k] → x10+k` 约定一致时，qd 可取 10+k）。
- 经典指令（`li/add/beq/...`）继续读写通用寄存器，形成经典-量子混合执行。

## 5. 示例程序

制备 2 比特 Bell 态并测量：

```
qinit 2
li x10, 0          # 清零 x10（准备接测量结果）
qh q0              # H q0
qcx q0, q1         # CNOT q0→q1
qmeas x10, q0      # 测量 q0 → x10
qmeas x11, q1      # 测量 q1 → x11
j DONE
DONE:
```

对应机器码（节选，指令字驱动）：
```
qinit 2                -> 0x1801000B  (funct7=0x0C, qa=2? 见下)
qh q0                  -> 0x0200000B  (funct7=0x01, qa=0, funct3=0, opcode=0x0B)
qcx q0, q1             -> 0x1010100B  (funct7=0x08, qa=0, qb=1, funct3=1, opcode=0x0B)
qmeas x10, q0          -> 0x1600050B  (funct7=0x0B, qa=0, qd=10, funct3=0, opcode=0x0B)
```

> `qinit 2` 编码为 `0x1801000B`：funct7=0x0C 标记 qinit，rs1 字段承载比特数 n=1
> （`qinit 2` 中参数经 `_qidx` 解析为 n=1 并存入 rs1=0x01）。以反汇编器实际输出为准
> （见 `quantum_riscv_emulator.py` 的 `__main__`）。

## 6. 指令字驱动的执行链路

本扩展采用**汇编 → 机器码 → 解码 → 执行**的完整链路（主办方 Bonus 方向 1）：

```
汇编文本 (load_program)
   │  assemble()：每条指令编码为 32 位指令字
   ▼
指令字列表 words: List[int]
   │  execute()：逐条取出指令字
   ▼
decode_word(word)：解析 opcode / funct3 / funct7 / rd / rs1 / rs2 / imm 字段
   │  返回 (助记符, 参数)
   ▼
分派执行（标准指令 + 量子指令）
```

- `assemble()`：两遍扫描——第一遍收集指令与标签（标签→指令索引），第二遍解析
  分支目标，编码每条指令为标准 RISC-V（I/R/B/UJ 型）或 CUSTOM-0 量子指令字。
- `decode_word()`：读回 opcode、funct3、funct7、rs1、rs2、rd、imm，据此判定指令类型。
  自定义量子 opcode（0x0B）在此处真正参与运行。
- `load_machine_code(words)`：可直接加载已汇编的指令字运行（不经文本）。
- `disassemble()`：返回 (指令字, 助记符, 参数) 供验证/展示。

标准指令分支（beq/bne/j）的偏移按**指令索引**语义编码（与官方模拟器 `labels[label]`
为指令索引一致），编码进 12/20 位立即数。
