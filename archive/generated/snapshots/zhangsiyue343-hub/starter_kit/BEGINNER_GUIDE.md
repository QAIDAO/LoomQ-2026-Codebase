> 你是**第一次碰量子计算**的人？很好，这条路径就是为你设计的。
> 你不需要懂任何物理，只需要跟着下面 4 步，5 分钟内跑出你人生第一个量子程序。

---

## 1. 量子是什么？（3 句话版）

- **量子比特（qubit）**：一个"魔法硬币"。普通硬币只有正/反，魔法硬币在被看之前
  是"正反叠加"，一"看"（测量）才确定正或反。
- **量子门（gate）**：对硬币的操作。`h` 让硬币进入叠加态，`cx` 让两枚硬币
  **纠缠**——从此它们永远同面（都是正面或都是反面）。
- **测量（measure）**："看一眼"硬币，记录结果。跑很多次，数一数正反各多少次。

> 想更深入了解？`starter_kit/QUANTUM_101.md` 是 30 分钟的完整入门手册。

## 2. 一条命令运行你的第一个量子程序

无需任何账号、无需联网、无需安装（Python 标准库即可）：

```bash
cd starter_kit
python3 evaluator.py --level l1 --target spinq,originq,braket
```

你会看到三平台跑通 Bell 电路（2 个纠缠的量子比特），每个都输出类似：

```
[PASS] l1:bell.qasm:spinq: fidelity threshold met
```

**这就是"指挥了一台量子计算机"**——虽然是模拟器，但逻辑与真机完全一致。

## 3. 用中文指挥量子计算机（智能体 + CLI）

LoomQ 的智能体能听懂自然语言。交互模式：

```bash
cd starter_kit
python3 cli_agent.py --interactive
```

你只需要**说人话**，例如：

```
你 > 生成 3 比特 GHZ 态并测量
```

智能体会自动：理解意图 → 生成 QASM 电路 → 自验 → 在模拟器上运行 → 把结果
翻译成你能看懂的话：

```
测量结果分布（共 8192 次采样）：
  |000> : 50.1%
  |111> : 49.9%
提示：|000> 和 |111> 各占约一半 —— 这正是一个最大纠缠态（GHZ/贝尔态）的特征，
量子比特之间确实发生了纠缠。
```

你不需要懂任何语法。打错/电路报错时，智能体会**自己修复并重试**。

## 5. 出错时怎么办（错误恢复引导）

- **听不懂我的自然语言？** 直接说"生成 X 态并测量"，X 可以是 GHZ、贝尔、均匀叠加。
- **智能体返回的不是电路？** 它可能把你的话理解成了"选平台"——加上"生成/写出/帮我写"
  等词即可。
- **真机提交失败？** CLI 会提示"真机提交失败 + 原因"。这**不影响你体验**——
  用本地模拟器（默认）即可完成全部学习流程。真机需要登录凭证（见 ARCHITECTURE.md
  环境变量配置章节）。
- **想可视化？** CLI 输出的分布本身就是可视化；结果自动按你认识的"百分比 + 人话"呈现。
