# 零基础首次运行指南

> 目标读者：从未接触过量子计算、也没配过任何开发环境的人。
> 全程 **不需要安装第三方库、不需要注册账号、不需要联网**。

## 第 0 步：确认 Python（≥3.10）

打开终端（Windows 按 `Win+R` 输入 `cmd`）：

```bash
python --version
```

显示 `3.10` 或更高即可。没有装？去 https://www.python.org/downloads/ 一路下一步。

## 第 1 步：启动对话控制台

进入本仓库目录：

```bash
cd LoomQ-2026/starter_kit
python cli.py
```

你会看到 ASCII 横幅和提示符 `loomq>`。这就是全部的"安装过程"。

## 第 2 步：跟着内置引导走一遍

在提示符后输入：

```text
:start
```

它会用 4 步带你完成：概念速览 → 用一句中文生成电路 → 本地真实运行 →
读懂测量分布。全程约一分钟。

## 第 3 步：自己说一个需求

直接用中文输入，例如：

* `生成一个 3 比特 GHZ 态并进行全测量`
* `帮我生成 5 比特均匀叠加态`
* `我需要跑一个 15 比特电路，要求零排队免费，选哪个平台？`

系统会返回 QASM 代码、自动在本地模拟器验证，并画出结果直方图。

## 看不懂结果？两个救命命令

| 命令 | 作用 |
|---|---|
| `:explain 纠缠` | 概念速查（叠加 / 纠缠 / 测量 / H门 / GHZ…） |
| 把报错代码贴进对话框 | 智能体会修好代码并解释原因 |

## 进阶（可选）

* 接入大模型获得更强的生成能力：设置三个环境变量
  `LOOMQ_LLM_BASE_URL` / `LOOMQ_LLM_API_KEY` / `LOOMQ_LLM_MODEL`
  （详见 starter_kit/README.md 的 L2 章节）。不配置也完全可用——
  内置确定性模板引擎离线工作。
* 运行完整自测：仓库根目录执行
  `python -m unittest discover -s tests`
