概念 1 / 4

量子比特，是保存量子信息的基本单位

信息载体

普通比特的格子保存 0 或 1；量子比特的格子保存量子状态。

两个基础状态

|0⟩ 与 |1⟩

| ⟩ 表示“这是一个状态”。|0⟩ 读作“零态”，|1⟩ 读作“一态”；中间的 0、1 是状态名称

直观比喻

像一枚正在旋转的硬币

看清之前，先同时保留正面和反面两种可能；测量就像让硬币停下，一次只会看到一面。这个比喻帮助理解“可能性”，量子比特并不是真的硬币。
