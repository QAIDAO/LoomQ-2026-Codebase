这块玻璃会干什么？ 激光笔只射出一束光。玻璃把它劈成两束：上面一束当 1，下面一束当 0。以前我们一次只能对盒子输入一个数，操作两次之后，我们才能够确定盒子里的程序是一样组还是不一样组。有了它，我们只需要对盒子操作一次，答案就能揭晓。

刚才那一幕，不是我们编出来的戏法。

1985 年，物理学家大卫·多伊奇（David Deutsch）问过同一个问题：一个只会回答 0 或 1 的黑盒，想知道它对两次输入的回答是不是一样，普通计算机必须问两次。他想出的办法是：让两种输入一起走进盒子，只问一次，看两路能不能对上。这就是 Deutsch–Jozsa 算法。

尽管 Deutsch–Jozsa 算法有很明显的人工构造痕迹，实际价值不明显。但是它清楚地显示了量子计算可以在某些特定的场景下远远超过经典计算，从而为寻找更有价值的量子算法提供了线索。
