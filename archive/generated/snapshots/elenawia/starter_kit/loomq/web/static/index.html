为什么要连接多个平台？

同一份实验，交给不同平台。

每台量子计算机都有自己的“方言”和脾气——同一份实验，在不同芯片上的结果会略有不同。LoomQ 把它写成三家各自的方言、并排放在一起：不用看懂任何一家的规则，就能比较哪些一致、哪些不同。
