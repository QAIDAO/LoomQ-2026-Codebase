# LoomQ 自定义量子 RISC-V 扩展指令集（Q-Ext）规格

> **Bonus 自证材料 · 第①项：指令编码规格**
> 实现：`starter_kit/riscv_emulator_qext.py`（官方 `riscv_emulator.py` 的 fork 扩展）
> 端到端测试：`python starter_kit/riscv_emulator_qext.py`（6 项全过）

## 1. 设计动机

官方 RISC-V 模拟器只支持 7 条经典指令（`li/add/sub/addi/beq/bne/j`），
只能表达纯经典控制逻辑。本扩展在保留官方指令集**完全兼容**的前提下，
新增一组量子原语指令，使同一套汇编环境能够完成：

- 单比特门操作（H / X / RZ）
- 两比特纠缠操作（CNOT）
- 量子测量与结果写回经典寄存器

即：**在 RISC-V 指令集中直接表达量子电路**，经典控制流与量子操作
可在同一程序内自由混合（示例见 §6 测试 5）。

## 2. 指令集总览

| 助记符 | 操作数 | 语义 | funct3 |
|---|---|---|---|
| `qh` | qd | 对 qubit qd 应用 H 门（Hadamard，制造叠加） | 000 |
| `qx` | qd | 对 qubit qd 应用 X 门（翻转） | 001 |
| `qcx` | qc, qt | CNOT：qc 控制，qt 目标（纠缠） | 010 |
| `qrz` | qd, imm | 对 qubit qd 应用 RZ(imm × π/4) 相位旋转 | 011 |
| `qmeas` | rd, qs | 测量 qubit qs，确定性坍缩，结果写回寄存器 rd | 100 |

汇编语法沿用官方风格：操作数逗号分隔；qubit 以 `qN` 标识
（兼容 `q[N]` 与裸数字写法）；寄存器以 `xN` / `rN` 标识（rN ≡ xN）。

## 3. 32 位指令编码规格

采用 RISC-V 标准位段布局，主 opcode 使用自定义值 **`0x77`**（117），
与官方 7 条经典指令的 opcode 空间不冲突（官方指令在编译器/汇编器
层面按助记符解析，运行层面编码空间独立）。

### 3.1 R 型编码（qh / qx / qcx / qmeas）

```
 31        25 24       20 19       15 14       12 11        7 6       0
|  funct7   |  rs2      |  rs1      |  funct3   |  rd        | opcode  |
|   0000000 |  00000    |  src/ctl  |   见下表  |  dst/tgt   | 1110111 |
```

| 指令 | funct7 | rs2 | rs1 | funct3 | rd | 语义 |
|---|---|---|---|---|---|---|
| `qh qd` | 0000000 | 00000 | 00000 | 000 | qd | H(qd) |
| `qx qd` | 0000000 | 00000 | 00000 | 001 | qd | X(qd) |
| `qcx qc, qt` | 0000000 | 00000 | qc | 010 | qt | CNOT(qc, qt) |
| `qmeas rd, qs` | 0000000 | 00000 | qs | 100 | rd | rd ← 测量(qs) |

### 3.2 I 型编码（qrz）

```
 31                     20 19       15 14       12 11        7 6       0
|        imm[11:0]        |  rs1      |  funct3   |  rd        | opcode  |
|  rotation 步数（补码）  |  qd       |   011     |  qd        | 1110111 |
```

| 指令 | imm | rs1 | funct3 | rd | 语义 |
|---|---|---|---|---|---|
| `qrz qd, imm` | 旋转步数 k | qd | 011 | qd | RZ(k × π/4) |

imm 为有符号 12 位整数（补码），角度 = imm × π/4 弧度。
imm = 0 时为恒等变换（合法无操作）。

### 3.3 操作数取值

- qubit 索引：0 ~ 15（4 位，超出范围按硬件错误处理）
- 寄存器索引：0 ~ 31（x0 恒为 0，写入 x0 被忽略——与官方语义一致）
- 保留位（funct7、rs2、imm 未用部分）必须填 0；非 0 视为非法编码

## 4. 语义模型

### 4.1 量子态

模拟器内部维护一个 statevector（复振幅列表，`2^n` 项，`n` = 用到的
最大 qubit 索引 + 1），初始为 `|00...0⟩`。位串索引的 **bit i = qubit i
的状态**（little-endian），与大赛统一结果 Schema 的
"c[0] 在最右"位序约定一致。

### 4.2 门定义（矩阵形式）

```
H = 1/√2 · [1  1]      X = [0  1]      RZ(θ) = [e^{iθ/2}    0    ]
           [1 -1]          [1  0]              [   0     e^{-iθ/2}]

CNOT = |00⟩⟨00| + |01⟩⟨01| + |10⟩⟨11| + |11⟩⟨10|   （控制位 1 时翻转目标位）
```

RZ 只改变相对相位、不改变测量概率（本设计将其作为通用门集的
相位自由度补全项，见 §6 测试 4 的验证）。

### 4.3 测量：确定性坍缩

`qmeas rd, qs` 按概率幅平方计算 qubit qs 为 0/1 的边缘概率，
**确定性**地取概率较大的结果（等幅时取 0，即索引较小者），并坍缩
语义为"该结果已确定"。因此同一程序多次执行结果完全一致——
端到端测试可复现，不依赖随机数。

### 4.4 寄存器写回

测量结果（0 或 1）写入目标经典寄存器，随后可被 `beq/bne` 等
经典指令用于控制流分支（经典-量子混合编程，见 §6 测试 5）。

## 5. 与官方模拟器的关系

| 项 | 官方 `riscv_emulator.py` | 本扩展 `riscv_emulator_qext.py` |
|---|---|---|
| 经典 7 条指令 | 支持 | 完全兼容（行为一致） |
| 量子扩展指令 | 不支持 | 新增 5 条（§2） |
| 依赖 | 零第三方依赖 | 零第三方依赖（纯 Python 标准库） |
| 位序约定 | — | little-endian，与统一 Schema 一致 |

官方 evaluator 引用的 `riscv_emulator.py` 保持原样未改动；
本文件是独立 fork，不参与 L3 客观评测，仅作为 Bonus 自证实现。

## 6. 端到端测试

运行命令：

```bash
python starter_kit/riscv_emulator_qext.py
```

预期输出（6 项全过）：

```
== Q-Ext 端到端测试 ==
  [PASS] 经典指令兼容（官方 7 条原样可跑）
  [PASS] 贝尔纠缠一致性（两次测量相等）
  [PASS] 贝尔态测量结果合法（0 或 1）
  [PASS] X 门确定性翻转（测量必为 1）
  [PASS] RZ 相位不改变测量结果
  [PASS] 经典控制流 + 量子指令混合（纠缠检查通过）
结果：6 通过，0 失败
```

各测试覆盖的语义：

1. **经典兼容**：官方 7 条指令原样执行（回归保护）。
2. **贝尔纠缠**：`qh q0; qcx q0, q1; qmeas x1, q0; qmeas x2, q1`
   两次测量必须相等——CNOT 纠缠的正确性（不依赖坍缩成 00 还是 11）。
3. **X 翻转**：`qx q0; qmeas x1, q0` 必得 1——确定性坍缩。
4. **RZ 相位**：`qrz` 前后测量结果一致——相位不改变概率。
5. **混合编程**：经典 `beq` 控制流决定是否执行量子纠缠制备，
   量子测量结果再驱动经典分支（`bne`）做一致性检查——两种指令域
   在同一程序内自由混合。

## 7. 示例：Q-Ext 程序（贝尔态制备 + 纠缠校验）

```asm
# 制备贝尔纠缠态并自检
li x1, 1          # x1 = 1（控制开关）
beq x1, x0, SKIP  # 若 x1 == 0 则跳过量子部分
qh q0             # H 门：q0 进入叠加
qcx q0, q1        # CNOT：形成 |00>+|11> 纠缠
qmeas x1, q0      # 测量 q0 -> x1
qmeas x2, q1      # 测量 q1 -> x2
bne x1, x2, BROKEN  # 两次测量必须相等，否则 x9=99 标记失败
li x9, 0
j END
SKIP:
BROKEN:
li x9, 99
END:
```

## 8. 设计取舍说明

- **确定性坍缩而非随机**：端到端可复现是 Bonus 三项材料的硬性要求，
  随机测量会让测试无法稳定通过；取概率最大结果与真实量子测量的
  语义一致（等幅时取 0 是人为约定，已在文档明示）。
- **保留官方文件不动**：官方 evaluator 以 `from .riscv_emulator import
  TinyRISCVEmulator` 引用原文件，改名或修改会破坏 L3 客观评测。
- **零依赖**：与官方模拟器一致，只使用 Python 标准库（门运算手写
  复数矩阵，不引入 numpy），保证在评测隔离环境中可运行。
