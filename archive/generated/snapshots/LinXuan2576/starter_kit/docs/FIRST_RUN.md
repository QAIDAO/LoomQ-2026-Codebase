# 零基础首次运行指南

> 你没接触过量子计算？没关系。本指南 10 分钟带你从零跑通第一条量子电路。

## 你需要什么

- 一台装了 Python 3.10 的电脑（Windows / macOS / Linux 均可）
- 能上网（安装依赖用；装好后**离线也能跑**）

不需要：量子物理知识、云平台账号、任何量子 SDK 经验。

## 第 1 步：安装依赖（3 分钟）

```bash
cd starter_kit
pip install -r requirements.txt
```

## 第 2 步：说一句人话（2 分钟）

```bash
python cli.py
```

出现 `LoomQ-Agent >` 提示符后，输入：

```
生成一个2比特贝尔态电路
```

你会看到（示例输出）：

```
>> Agent 生成电路，目标后端：braket
>> 电路运行结果：
=== 后端 braket_local_simulator（总采样 8192 次）===
  "11" ████████████████████  50.2%
  "00" ████████████████████  49.8%
```

恭喜！你刚刚完成了一次完整的量子计算：**电路生成 → 自动验证 → 执行 → 结果可视化**。

## 第 3 步：看懂结果（3 分钟）

上面的结果是什么意思？

- 你的电路制备了一个**贝尔态**——两个量子比特的**纠缠**状态
- 测量时它只会坍缩成 `00` 或 `11` 两种结果，各占约 50%
- 关键点：**永远是成对的**（`00` 或 `11`，不会出现 `01`、`10`）——这就是"纠缠"：两个比特共享同一个命运
- 这是量子世界最著名的现象之一，爱因斯坦称之为"幽灵般的超距作用"

不懂"叠加"、"纠缠"、"坍缩"？看 [`QUANTUM_101.md`](../QUANTUM_101.md)，用日常比喻解释。

## 第 4 步：再试几个（2 分钟）

| 你输入 | 会发生什么 |
|---|---|
| `生成一个3比特GHZ纠缠态` | 三个比特全部纠缠，结果只有 `000` 或 `111` |
| `/help` | 查看所有命令 |
| `/backends` | 查看三家量子云平台的能力对比 |
| 粘贴一段 `OPENQASM 2.0; ...` 程序 | 直接运行你（或别人）写的电路 |
| `/run circuits/bell.qasm spinq 8192` | 离线跑本地电路文件 |

## 出错了怎么办？

- **Agent 没听懂**：换个说法再试，比如"帮我生成一个贝尔态"、用英语 "make a Bell state"
- **提示缺少环境变量**：自然语言模式需要配置 `LOOMQ_LLM_*`（见 `l2_agent.py` 注释）；不想配置也可以直接用粘贴 QASM 或 `/run` 模式，完全离线
- **结果不是 50/50**：正常，8192 次采样有轻微统计涨落；误差在 1% 以内都算正确
