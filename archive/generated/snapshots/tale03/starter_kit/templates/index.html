Qat / 喵子

你用的手机和电脑，所有信息都是用 0 和 1 表示的。每一个 0 或 1 叫一个「比特」。

量子计算机不一样——它用的是「量子比特」。量子比特可以同时是 0 和 1，直到你去看它才变成其中一个。这种性质叫「叠加」。靠它，量子计算机能在密码破解、药物研发等领域，做到普通计算机做不到的事。

操作量子比特需要写一种叫 QASM 的专用代码——大多数人在这一步就被挡在了门外。更麻烦的是，不同的量子计算机说不同的"方言"，同一个程序要翻译成三种格式才能在三台机器上跑。

喵子是你的量子翻译官。它能帮你做三件事：

① 生成代码 — 用人话描述实验，喵子写好代码并运行

② 修复代码 — QASM 写错了？发给喵子，它帮你修

③ 选择平台 — 不知道用哪台量子计算机？告诉喵子你的需求

不需要学编程。不需要懂物理。说人话就行。
