# LoomQ 量子 RISC-V 扩展指令 — 编码规格文档

## 概述

本文档定义了一套自定义 RISC-V 指令扩展，将量子门操作编码为标准 RISC-V 指令格式。这使得经典控制流和量子操作可以共存于同一条指令流中，实现真正的量子-经典统一程序。

## 操作码分配

所有量子指令使用自定义操作码 `0001011`（十六进制 0x0B），属于 RISC-V 预留的 custom-0 编码空间，不与任何标准指令冲突。

## 指令格式（R-type）

```
31      25  24    20  19    15  14  12  11     7  6      0
┌─────────┬────────┬────────┬───────┬────────┬──────────┐
│ funct7  │  rs2   │  rs1   │funct3 │   rd   │  opcode  │
│ 7 位    │ 5 位   │ 5 位   │ 3 位  │ 5 位   │  7 位    │
└─────────┴────────┴────────┴───────┴────────┴──────────┘
                                               0001011
```

## 字段定义

| 字段    | 位域  | 用途 |
|---------|-------|------|
| opcode  | 6:0   | `0001011` — 标识量子指令 |
| rd      | 11:7  | 经典目标寄存器（用于 MEASURE） |
| funct3  | 14:12 | 量子门选择器（见下表） |
| rs1     | 19:15 | 目标量子比特索引（0–31） |
| rs2     | 24:20 | 控制量子比特 / 第二量子比特（0–31） |
| funct7  | 31:25 | 第三量子比特（用于 CCX）或参数 ID |

## 量子门编码表

| funct3 | 助记符     | 名称         | 操作数                 | 说明 |
|--------|-----------|-------------|----------------------|------|
| 000    | `qh`      | Hadamard 门 | rs1=目标比特            | 对目标比特施加 H 门 |
| 001    | `qx`      | Pauli-X 门  | rs1=目标比特            | 对目标比特施加 X 门（翻转） |
| 010    | `qcx`     | CNOT 门     | rs1=目标, rs2=控制      | 受控非门 |
| 011    | `qmeasure`| 测量        | rs1=量子比特, rd=经典寄存器 | 测量量子比特，结果写入寄存器 |
| 100    | `qs`      | S 门        | rs1=目标比特            | 对目标比特施加 S 门 |
| 101    | `qt`      | T 门        | rs1=目标比特            | 对目标比特施加 T 门 |
| 110    | `qswap`   | SWAP 门     | rs1=比特1, rs2=比特2    | 交换两个量子比特 |
| 111    | `qccx`    | Toffoli 门  | rs1=目标, rs2=控制1, funct7[4:0]=控制2 | 三量子比特门 |

## 汇编语法

```asm
qh    q0           # 对量子比特 0 施加 H 门
qx    q1           # 对量子比特 1 施加 X 门
qcx   q0, q1       # CNOT：控制=q0，目标=q1
qmeasure q0, x10   # 测量量子比特 0，结果存入寄存器 x10
qs    q2           # 对量子比特 2 施加 S 门
qt    q0           # 对量子比特 0 施加 T 门
qswap q0, q1       # 交换量子比特 0 和 1
qccx  q0, q1, q2   # Toffoli：控制1=q0，控制2=q1，目标=q2
```

## 二进制编码示例

```
二进制: 0000000 00000 00000 000 00000 0001011
十六进制: 0x0000000B
```

```
二进制: 0000000 00000 00000 011 01010 0001011

```

## 量子-经典协作示例

量子指令和经典指令共存于同一条指令流中。`qmeasure` 指令是两个域之间的桥梁——它将量子测量结果写入经典寄存器，之后可用于条件分支：

```asm
qh       q0           # 将量子比特 0 置于叠加态
qcx      q0, q1       # 与量子比特 1 纠缠
qmeasure q0, x10      # 测量量子比特 0 → 结果存入 x10
qmeasure q1, x11      # 测量量子比特 1 → 结果存入 x11
li       x20, 1       # 加载比较值
beq      x10, x20, EXCITED  # 如果测量到 |1⟩ 则跳转
li       x1, 10       # 基态路径
j        END
EXCITED:
li       x1, 100      # 激发态路径
END:
addi     x1, x1, 5    # 继续经典计算
```

## 模拟器行为

扩展模拟器对量子指令的处理方式：

- **门指令**（`qh`, `qx`, `qcx`, `qs`, `qt`, `qswap`, `qccx`）：记录到量子操作追踪列表中。模拟器不模拟量子物理——它记录操作序列用于验证。
- **`qmeasure`**：从预注入的测量结果表中读取值（量子比特索引 → 经典值），写入目标寄存器。这使得在所有可能的测量结果下都能确定性地测试经典控制流。

## 兼容性

- 仅使用 RISC-V custom-0 操作码空间——不与 RV32I/RV64I 冲突
- 经典指令保持不变
- 该扩展向前兼容：未使用的 funct3/funct7 值预留给未来的含参量子门（如 RZ(θ)、RY(θ)）
