# Quantum eXtension (QX) — LoomQ 自定义量子 RISC-V 指令规范

版本 1.0 · 2026-08-22 · 配套实现 `riscv_quantum_emulator.py` · 端到端测试
`test_quantum_riscv.py`

## 1. 动机

官方 `riscv_emulator.py` 只覆盖经典子集（li/add/sub/addi/beq/bne/j），
Hybrid-QASM 的经典块也只能在测量结束后读取结果。真实量子算法（VQE、变分
线路、量子纠错控制流）需要的东西是：**经典程序在量子演化过程中读取量子态、
计算参数、再驱动后续量子操作**——一个闭环。

QX 扩展在官方模拟器上加一组量子指令，把 3~8 比特的状态向量机塞进同一个
RISC-V 核心里。标志性能力：

```asm
qry  x5, q0        # 用寄存器里的角度做旋转 —— 角度是刚才算出来的
qprob x6, q0       # 把 P(q0=1) 写进经典寄存器 —— 经典世界看见量子世界
beq  x6, x7, TUNE  # 对概率做分支 —— 反馈闭环成立
```

## 2. 指令集

### 2.1 伪指令 / 指示符

| 形式 | 说明 |
|---|---|
| `.qubits N` | 声明 N 个量子比特（1 ≤ N ≤ 8），必须在第一条量子指令前；全部初态 \|0…0⟩ |

### 2.2 量子指令

| 助记符 | 操作数 | 语义 |
|---|---|---|
| `qh qi` | 寄存器名 q0..q7 | 对 qi 施加 Hadamard |
| `qx qi` | 同上 | 对 qi 施加 Pauli-X |
| `qry SRC, qi` | SRC ∈ {立即数, x寄存器} | Ry(θ) 作用于 qi，θ = SRC值 / 1000（毫弧度定点）|
| `qrz SRC, qi` | 同上 | Rz(θ) 作用于 qi |
| `qcx qc, qt` | 控制位 qc、目标位 qt | CNOT(qc → qt) |
| `qprob xRd, qi` | 目的寄存器 + 量子位 | xRd ← round(P(qi=\|1⟩) × 10⁶)，**确定性**，不坍缩 |

约定：

- **定点角**：寄存器只能存整数，故角度一律用毫弧度定点表示
  （π/2 → `1571`）。立即数写法 `qry 785, q0` 等价。
- **qprob 不坍缩**：它是一次"观察"，不是测量——态矢量保持相干，因此同一段
  量子程序可以反复读取概率并分支，行为完全确定、可穷举测试。
- **位序与全站一致**：状态向量索引 `idx = Σ 2^k·bit(qk)`，即最低位是 q0，
  与 LoomQ 计数键"最右字符 = c[0]"同一约定。
- **步数上限**：沿用官方模拟器 `max_steps=1000` 防死循环。

## 3. 二进制编码映射（custom-0 空间）

真实 RISC-V 为自定义指令预留 `custom-0`（opcode `0x0B`）与 `custom-1`
（`0x5B`）。QX 全部落在 custom-0，字段布局沿用 R 型：

```text
31        25 24     20 19     15 14  12 11    7 6   0
[  funct7   ][  rs2    ][  rs1    ][funct3][  rd   ][0001111]  ← 0x0F? 否：
                                                        opcode = 0x0B
```

| 指令 | funct7 | rs2 | rs1 | funct3 | rd | 说明 |
|---|---|---|---|---|---|---|
| `qh`   | 0000001 | qubit | 0 | 000 | 0 | 单比特门组共用 funct7=0000001 |
| `qx`   | 0000010 | qubit | 0 | 000 | 0 | |
| `qry`  | 0000011 | qubit | 角度源寄存器 | 000 | 0 | 立即数形式走 R 型 + imm 变体（funct3=001 时 rs2 存毫弧度 immediat高12位）|
| `qrz`  | 0000100 | qubit | 角度源寄存器 | 000 | 0 | |
| `qcx`  | 0000101 | target | control | 000 | 0 | |
| `qprob`| 0000110 | qubit | 0 | 000 | 目的寄存器 | 结果写 rd |

汇编层无需手写二进制——模拟器按上表即查即执行；表的存在保证这套助记符
可以无损落进真实 RISC-V 工具链的自定义指令槽。

## 4. 与官方模拟器的关系

`riscv_quantum_emulator.py` **继承**官方 `TinyRISCVEmulator`：全部经典指令
（li/add/sub/addi/beq/bne/j）、标签解析、max_steps 保护原封不动；仅重载
程序装载（识别 `.qubits` 与量子指令）与执行分发（追加量子语义）。官方测试
脚本在本模拟器上原样通过。

## 5. 端到端示例

见 `test_quantum_riscv.py::test_feedback_loop`：制备叠加 → 读概率 →
对概率等值分支 → 经典侧打标。以及相位可见性实验 `rz 不可见、干涉可见`：
`h; qrz 3142; h` 后 P(q0=1)=100%，证明 Rz 相位经干涉转化为可测强度。
