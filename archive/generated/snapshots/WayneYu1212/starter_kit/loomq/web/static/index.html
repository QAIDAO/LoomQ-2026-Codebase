量子计算在做什么？量子计算

一种利用量子系统来处理信息的计算方式。你现在不需要先学量子力学；这页只带你看懂一个最小实验。

量子计算也是在处理信息。普通计算机常用 bit，也就是 0 和 1；量子计算机使用 qubit，也就是量子比特。

先把它理解成：一种用量子系统处理信息的计算方式。

bit：普通计算机最基本的信息单位bit

普通计算机最基本的信息单位，通常用 0 或 1 表示。

02

量子比特是什么？

量子比特是量子计算里的基本信息单位。测量以后会读成 0 或 1；测量之前，它可以处在不同的量子状态。

CNOT 对 0 / 1 输入做什么？

第一个比特是控制位 q0，第二个比特是目标位 q1。点击一张卡，看清 CNOT 只会在控制位为 1 时翻转目标位。

控制位是 0：目标位不变。

q0 = 0→q1 = 0

控制位是 0：目标位不变。控制位是 1：目标位翻转。

CNOT 本身不等于“纠缠”。从 |00⟩ 出发，先对 q0 做 H，再做 CNOT，才得到这里的 Bell Φ+ 态。
