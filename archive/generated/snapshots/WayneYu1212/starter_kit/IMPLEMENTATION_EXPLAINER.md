# How LoomQ works (plain-language explainer)

> 这份文档用"没有量子背景也能懂"的话，讲清楚 LoomQ 内部是怎么工作的。评委如果问你"这个项目到底怎么实现的"，你可以用 2–3 分钟照着讲一遍。技术细节见 `ARCHITECTURE.md`。

## 一句话

用户用一句人话描述想要的量子程序 → LoomQ 把它变成一种统一的中间表示（IR）→ 再翻译成三家平台各自的语言 → 在真实 SDK 上运行 → 用**独立的第二个程序**先验证结果对不对，才展示给用户。

## 核心概念（用比喻）

- **OpenQASM**：量子程序的"源代码"，类似 Python/C。用户不直接写它。
- **Parser（解析器）**：把 QASM 文本拆成结构化数据。类似把一句话拆成"主语/动词/宾语"。
- **Typed IR（中间表示）**：解析后的一份**冻结的、不可变**的电路对象（谁、在哪个比特上、做什么操作）。所有下游都只认这一份，避免每个平台"各自解读"。
- **Emitter（发射器）**：把这份 IR 翻译成三个平台各自的语言（SpinQ QASM2、OriginIR、Braket QASM3）。**一个 IR，三份翻译，没有三套重复的解析器。**
- **Runner（运行器）**：调用真实的第三方 SDK（SpinQit / pyQPanda / Braket）去执行。
- **Verifier（验证器）**：一个**独立于 SDK 的参考模拟器**，用标准数学重新算一遍结果，确认 SDK 给的结果合理。它不冒充任何平台。
- **Counts normalization（结果规范化）**：把不同平台返回的计数格式统一成"little-endian，c[n-1]…c[0]"的标准形式，避免 pyQPanda 把字符串 `"11"` 误当十进制 11 这类坑。

## 三个评分层级

### L1：统一编译与三后端

用户给一个 Bell 或 GHZ 电路 → 解析 → IR → 三个 emitter 各生成一份目标代码 → 三个 SDK 各跑一次 → 独立 verifier 验证 fidelity。**同一个 IR 发往三个平台，结果一致。**

### L2：自然语言 → 程序（Agent）

用户说"生成一个 5 比特 GHZ 态并测量全部量子比特"：

1. 调用模型（`LOOMQ_LLM_*` 指定的真实 endpoint），模型返回一个**严格 JSON 计划**（生成 / 修复 / 推荐后端）。
2. 生成/修复的 QASM 走**和 L1 完全相同的** parser → validator → 独立模拟器。
3. 不合格就**返回给模型修复一次**（带清理后的错误信息）。
4. 推荐后端时，约束条件由**程序代码**对照官方 `backend_capabilities.json` 计算，模型不能凭空造后端 ID。
5. 只有"验证通过"的 QASM 或"查表得到的后端 ID"才会交给用户。

**关键**：模型只是"提出建议"，最终是否可信由**确定性程序**把关。不是靠关键词查表或样例匹配蒙答案。

### L3：混合量子-经典程序

L3 是带 `classical { ... }` 经典控制块的混合程序。LoomQ 用独立的 lexer/parser 把经典控制编译成官方 stock RISC-V 子集（`li/add/sub/addi/beq/bne/j`），量子操作保持原顺序。经典逻辑**从不使用 `eval`/`exec`**，是真正的 AST 编译。

### Custom Quantum RISC-V Bonus

在官方 RISC-V 模拟器里额外解码一组 `custom-0` 指令，每条指令会输出一个确定性的 `quantum_trace`（描述意图）。它**不写通用寄存器、不编造测量、不模拟振幅、也不声称是真机**。规格、编码、`.word` 端到端测试都在 `QUANTUM_RISCV_EXTENSION.md`。

## 硬件证据：模拟器 vs 真机

- **模拟器**：本地 SDK 运行，结果可复现，用于验证程序逻辑正确。
- **真机**：SpinQ（2 比特核磁）和 OriginQ（Wukong 180-2）各跑了一个 Bell 实验，保存了平台 job ID、原始导出、任务截图和哈希。**模拟器结果永远不会被描述成真机证据**；真机可追溯性由组委会登录平台复核。

## 为什么这么设计

- **一个 IR**：避免三个平台各自解读导致结果不一致。
- **独立 verifier**：不信任单一 SDK，也不信任模型自评。
- **诚实边界**：模拟器不冒充真机，本地 venv 不冒充 Docker，截图不冒充正式得分回执。
